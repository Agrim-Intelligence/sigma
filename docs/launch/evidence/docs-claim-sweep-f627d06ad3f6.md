## Defects

**D1 (false, fixed).** `README.md`, configuration table: `budget.max_tokens` was listed as 500,000. The scaffold template
sets 100,000,000, `docs/configuration.md` says 100,000,000, and the README's own known-limits paragraph says 100,000,000.
The table now reads 100,000,000. This is a B3 candidate (a README claim false on a supported cell: it understated
the default spend ceiling 200 times).

**D2 (false, fixed, two sites).** `docs/platform-support.md` said the full suite runs "on every push/PR" on Linux with
Python 3.10 to 3.13 and on macOS. `ci.yml` runs one macOS Python 3.12 leg (a subset that skips the heaviest test files)
on pushes and pull requests, and the full five-leg matrix nightly and on demand, as the README already said.
`CONTRIBUTING.md` said CI runs the full suite on those legs without the cadence. Both now state the cadence.

**S1 (stale, proposed `launch:next`, not filed).** `docs/public-snapshot.md` scale bullet quotes a build at roughly 800 files
and 17 MB taking 18 to 26 s and extrapolates 10x and 100x from it. A re-measure at 1237 files gives 40.3 s total.
The extrapolations in that bullet need re-deriving from the new figures; that is a measurement task, not a one-line
correction, so it was left alone. Proposed title: "Re-measure the public-tree build scale in docs/public-snapshot.md
(now 1237 files)". The "42 skills" figure sits inside a dated run record and was left as written.

## What this sweep is not

  `label-model`, `dossier-pipeline`, `cloud-sessions`, `backlog`, about 6,200 lines between them) were swept for
  count-noun phrases and numeric defaults only, and their behavioural statements were not re-verified.
- The 48 pages under `docs/` subdirectories (launch records, benchmark pages) were checked for path references only.
  Their numeric claims are the subject of other dimensions' evidence (D1, D3, D5) and were not re-checked here.
- Link and anchor checks are `tests/test_doc_links.py`'s; this run did not repeat them.
- The Python version floor stated in CONTRIBUTING (3.10) was not checked against the code.
- Claims about hosts other than Claude Code on macOS are only as good as `docs/platform-support.md` says; nothing here
  ran Codex, Cursor or Linux.
