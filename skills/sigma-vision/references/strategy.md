# Deep pass — Strategy (L2: the current-cycle bet)

Loaded on demand by `sigma-vision` for a deep Strategy pass. Fills the **## Strategy** section of
`.sdlc/context/north-star.md` — including the **non-goals**, which the plan-review alignment gate
enforces. Horizon: medium-term (revisit every ~6–8 weeks / cycle). The user owns the words.

## Pre-flight
- Vision should exist first — read the **## Vision** section; every strategic claim must trace to it.
  If Vision is empty, offer to draft it first (load `references/vision.md`).
- Read recent `git log`, open issues, and any roadmap in the repo for what the current cycle is really
  about. Draft a first pass; the user sets the real bets.

## Elicit (one or two at a time)
1. **The central bet** — one sentence: the single thing this cycle is betting on. What changes if it
   wins? If it fails?
2. **Target segment** — the specific cohort this cycle serves (not "everyone"). Why them, why now,
   what's their alternative today?
3. **Differentiation** — what can only this effort do, and is it durable for at least this cycle?
4. **Distribution** — concretely, how do those users find it this cycle? If "none yet," what's the
   bridge plan?
5. **Metrics + thresholds** — 2–3 leading indicators (not vanity). For each: the target, and the level
   that means "pivot."
6. **Non-goals** — name 3–5 tempting things you are deliberately *not* doing this cycle, each with
   why-deferred. (Plan-review blocks any plan that advances these.)
7. **Risks + assumptions** — what, if wrong, kills the bet? What's the earliest failure signal?

## Stress-test
- One bet, not five — a multi-bet "strategy" advances nothing.
- Does the bet advance the Vision, or quietly sidestep it?
- Are the metrics concrete enough to be falsifiable?

## Write into `## Strategy`
The bet · target segment · differentiation · distribution · metrics + thresholds · **non-goals** ·
risks. Never overwrite a filled tier without asking.
