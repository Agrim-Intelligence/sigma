# Research: #425 — terminate autowatch model process groups on timeout

Date: 2026-10-02

## Measured state

- `skills/sigma-loop/scripts/autowatch.py` `_run_drive` starts the driven model with a plain
  `subprocess.Popen(..., stdout=PIPE, stderr=PIPE)` (no `start_new_session`) and on
  `TimeoutExpired` calls `proc.kill()` — SIGKILL to the direct child only — then an UNBOUNDED
  `proc.communicate()`. Two defects follow:
  1. A descendant of the model (a tool subprocess, a shell, a server it started) is reparented
     and keeps running after autowatch reports `124 timed out` (threat model TM-10).
  2. A descendant that inherited the stdout/stderr pipe keeps it open, so the drain after the kill
     blocks until that descendant exits: the timeout does not actually bound the call.
- Callers: `autowatch._drive` (the tick) and `slack_commands_listen._dispatch`, which passes
  `on_spawn` to register the child pid as a liveness marker. With a new session the child pid is
  also the group id, so the marker stays meaningful.
- Existing group-kill code: `run_with_timeout.py` (a CLI wrapper that runs a *Python script* via
  `sys.executable`, inherits stdio, SIGKILL only, `taskkill /T /F` on win32) and
  `phase_report._kill_tree` (SIGKILL only). Neither is a reusable function with a SIGTERM grace,
  and `run_with_timeout` cannot launch an arbitrary `drive_cmd` (it prepends the interpreter) or
  capture stdout, which `_run_drive` must return. Reuse is therefore of the pattern
  (`start_new_session=True` + `os.killpg`), not the code.
- Windows: `taskkill /T` walks parent-pid bookkeeping; a descendant whose parent already exited is
  not reachable, and there is no SIGTERM-grace equivalent. The launch definition lists Windows as
  experimental, and `tests/test_windows_real.py` does not exercise autowatch. The guarantee cannot
  be made there, so the drive refuses.
- `docs/threat-model.md` TM-10 lists mitigation `none`; T5/T7 cite `autowatch.py:621`.

## Constraints

- `_run_drive` contract `(exit_code, stdout)`, never raises, `124` on timeout — kept.
- Residual: a descendant that calls `setsid` itself leaves the group and cannot be reached by a
  group signal; documented, and the post-kill drain is bounded so it cannot hang the tick.
