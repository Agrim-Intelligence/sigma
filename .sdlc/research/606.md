# #606 research (P2) - config.yml public-slug check

## Premise
STALE. `.github/ISSUE_TEMPLATE/config.yml:4` already reads
`https://github.com/Agrim-Intelligence/sigmaloop/security/advisories/new` (set in #699). No build-time
substitution is needed. What is missing is a guard that fails if it ever names any OTHER repo.

## Existing guard (partial)
`tests/test_release_consistency.py::test_public_tree_names_the_public_repo_not_the_working_repo` (l.86-94)
asserts README.md, config.yml, contract/golden/config.json, docs/board.md do not carry the PRIVATE slug
(regex negative lookahead) and that config.yml contains `Agrim-Intelligence/sigmaloop/security/advisories/new`.
Gap: it hardcodes the slug, runs on the private tree only, and does not read `definition.json`. It does
not catch a third repo (typo, fork, other org). The export builder has no check on this file.

  `({"status": not-applicable|unverifiable|mismatch|equal, ...}, findings)`; finding rules

  `- doctor slug: <status>` (l.543-544).

## Plan sketch
Add `_issue_template_slug(partial, definition_raw, blobs)` beside `_doctor_slug`: parse every
`github.com/<owner>/<repo>` in `.github/ISSUE_TEMPLATE/config.yml` of the export, compare each to
`public_repo`; statuses not-applicable (file absent) / unverifiable (no definition) / mismatch / equal;
rules `issue-template-slug-mismatch|unverifiable`; report `scans.issue_template_slug`; one `render_md` line;
append findings in the builder_findings block (l.1274). Tests: copy the 4-case table + a third-repo case;
red control: break the comparison. Docs: public-snapshot.md l.154 rule list. CHANGELOG bullet. Do not add
a regex of the private slug anywhere (tests already hold that guard).
