# Research: #684 default loop skips research, plan, plan-review, retro and records no review (B3)

## What the live run showed (2026-10-06, local-only, scaffolded config, one real upstream bug)
- Action log held 6 events: claimed, agent_dispatch, model_choice (tier off), verify_run, recorded done, agent_done.
- No research or plan artifact, no `phase_report` banner or cost line, no retro event; the independent review ran but only as journey prose.
- Cost: loop $0.743 + init $0.132 = $0.875, 173 s; the same task without Sigma $0.145, 37 s. Both fixes passed 312/312 hidden tests.

## Root cause (code, not model behaviour)
- Dispatch-per-phase is prose only (`references/running.md`, SKILL step 3); no Python can see whether a phase was dispatched, so nothing refused a `done` that skipped them.
- `phase_report.py` writes `phase` events only to the ledger (opt-in `journal`), never to the action log, so `log.py slots` cannot name a phase.
- The only gates that look at plan/plan-review (`gates.hard_plan_gate`, `gates.plan_review`) are default off and fire at `work.py pr`; local-only mode has no PR.
- `loop.py record done` (state.done_refusal) checks verify evidence only.

## Blast radius
- `skills/sigma-loop/scripts/actionlog.py` (vocabulary), `phase_report.py` (start/end writers), `work.py` (`record_plan_review`, new record-review, merge gate), `loop.py` (record done, new verbs), `state.py`/new `phase_gate.py` (the gate), `skills/sigma-init/templates/config.json.tmpl`, `docs/enforcement.md` (generated), README, SKILL.md, running.md.
- Every mode funnels `done` through `loop.py record`, so one gate there covers local-goals, issues and github; `work.py merge` is the second chokepoint for PR modes. reconcile-merges (a PR merged by someone else) must not strand: it is not gated.
- Existing tests call `record done` without phases: the gate is keyed on `gates.phase_record.enabled`; the scaffold template ships true, an absent key is off.

## Constraints
- Host-agnostic: Python in Sigma's scripts; no hook is load-bearing.
- Independence is asked, not proved: the record proves a phase boundary and verdict were recorded, and for a subagent route that a dispatched agent id exists in the host's own transcript store.
- Cost: measured before and after; the trivial lever waives only research and retro.
