# Research: #697 launch hardening 1/2

Owner decision 2026-10-06 (severity review, launch:next, intake-freeze exception for exactly this list). Findings reproduced first-hand in the severity review; re-read in code here.

## Blast radius per item
- (a) `sources.fetch_comments` (drops `authorAssociation`; read by `backlog_check._fetch_scrubbed_comments` -> `cross_check` dismissal scan, `auto_unpark._is_exempt` keep-parked, plus comment_watch and doctor which read no markers) and `GitHubSource.fetch_comments_strict` (raw gh comments; markers read by `loop.decompose_check` decompose-filed, `loop.design_check` design-filed, `feature_owner`, `feature_propagate`, `feature_labels`, `acceptance` dedupe, `review_context` research-comment check which is not a marker). `gh issue view --json comments` returns `authorAssociation` on each comment (verified live). #635 already defined the trust set in `work._TRUSTED_ASSOCIATIONS` for PR comments only.
- (b) `loop.py` `spend` verb (`int(argv[3])`, then `state.add_tokens`); `state.add_tokens`; only other producer is `phase_report.cmd_end` (non-negative).
- (c) `work.merge`: two `gh pr merge` calls (arm `--auto`, direct). `gate()` already refuses unless the PR head equals the worktree head and records it as `final_data["headRefOid"]`; `normalise_ci_rollup(final_data)["head_sha"]` is that vetted head. `merge_design` merges a design PR with no vetted head: out of scope, follow-up.
- (d) `work._unresolved_threads`: GraphQL `reviewThreads(first:100)` with no cursor; fail-open to 0.
- (e) `channel_notify._real_post`: `urllib.request.urlopen` honours `http_proxy`/`HTTPS_PROXY`; the URL is already gated local-only by `_local_webhook_url`.

## Constraints
- Fail closed: an untrusted marker is ignored loudly (one stderr line naming commenter and association), never honoured; a marker comment with no `authorAssociation` key at all raises in the strict read (callers already park or skip on a strict-read raise).
- Loop's own markers are posted by the operator's gh account (OWNER/MEMBER/COLLABORATOR); a bot or NONE-association token would see its own markers ignored: duplicate flag comment, or a second decomposition filing. Documented as the limit.
- No new config, no new network call: the filter reads data the existing call already returns.

## Size
Small each. Total roughly 120 changed source lines plus tests.
