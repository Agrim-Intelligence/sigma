# #280 research — loop-created board keeps GitHub's `In progress`; card moves silently no-op

## Question
Does a board the loop creates itself (`sources.GitHubSource._ensure_board`, owner has zero boards)
keep a Status option spelled differently from `project.columns.in_progress` (`In Progress`), so
`mark_in_progress` writes nothing and says nothing? The issue was unverified against real GitHub.

## Evidence
1. **Real GitHub, read-only (2026-09-29).** One GraphQL *query* over the org's 14 Projects v2 boards
   (no mutation). Both spellings are live on default-shaped boards:
   - `Todo / In progress / Done` on 3 boards, plus one titled with the loop's own default
     `<repo> — SDLC` (`_proj_title`), carrying a DUPLICATED `In progress` lane (#1492-era symptom).
   - `Todo / In Progress / Done` on 3 boards (two are web-UI "untitled project" boards).
   - This repo's own board #17 (set up by board_setup.py): `Backlog, Ready, In Progress, QC, Done,
     Blocked, Parked`.
   What `createProjectV2` / `gh project create` yields for a brand-new board *today* was NOT measured
   (that needs a mutation on real GitHub, forbidden here). Conclusion: neither spelling can be assumed.
2. **Fake, before the fix.** `tests/boardfake.py`'s fresh board = GitHub defaults `Todo / In progress
   / Done`. Owner with no boards -> `_ensure_board` creates -> after its option rewrite the Status
   options are `Backlog, Ready, In progress, QC, Done, Blocked, Parked` -> `mark_in_progress("11")`
   leaves the card with Status None and prints NOTHING. **Proven** (for any board GitHub hands out
   spelled `In progress`).
3. **Mechanism.** `_ensure_status_field`'s `created_now` branch passes `rename={"Todo": backlog}`
   only. `_options_mutation` rule 1 (#1492) claims `In progress` for desired `In Progress` under
   GitHub's spelling. `_status_options` is keyed by board spelling and `_set_board_status` does an
   exact `.get(status_name)` -> None -> returns False, silently. Same exact lookup in
   `_apply_custom_fields` (backlog), `_sync_backlog` (seed) and `_ready_lane` (Ready).
4. **#235 precedent.** board_setup.py's fresh path already renames `Todo` AND `In progress`; its
   adoption path maps case variants into `project.columns` (never renames).
