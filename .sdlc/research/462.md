## Who writes them, who reads them
- Writers: the Plan, Research and Goal phases (`agrim-plan`, `agrim-research`, `acceptance.py record`),
  one file per goal, filed in the main checkout and committed on the goal branch by `work.py commit`.
  All under the project's own `.sdlc/`; none under a host configuration root.
- `.gitignore` re-includes `.sdlc/plans/`, `.sdlc/research/`, `.sdlc/acceptance/` (tracked) and ignores
  `.sdlc/plans/{triage,scope,reconcile}/` (local only, one json+md per run, never committed).
- Readers, by goal stem only: `work.py` (`pr` refuses without the plan; `record-plan-review` and the pr
  gate bind the plan sha256), `review_context.py` (`phase_doc_file`, brief packs from the branch),
  `acceptance.py` (`refusal`, `MAX_BYTES` 32 KiB read and write cap). Two hooks run
  `find .sdlc/plans -name '*.md' -mmin -N` on every source edit / stop. Nothing reads another goal's file
  after its PR merges, but the history is the project's audit trail, so deleting is not a candidate.
- Public snapshot: `tools/public-manifest.txt` and the builder are not in this repository, so whether the
  snapshot carries `.sdlc/` cannot be determined here. `tests/public_surface.py` in tree mode treats every
  tracked path as shipped and the exposure scan already reports two findings in tracked records.
