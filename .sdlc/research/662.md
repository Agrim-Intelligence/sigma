## Risks / findings that change the plan
1. **No real Architecture section to use as fixture.** The root checkout has NO `.sdlc/context/` at all (and no `.sdlc/decisions.json`). The only north-star on disk is `.sdlc/work/1379/.sdlc/context/north-star.md` (21 lines, headings: Authority and scope / Product boundaries / Source verification; a rules-only stub, no `## Architecture`). So Sigma's own repo has zero numbered architecture rules; `/sigma-doctor rules` on Sigma itself would report "no Architecture section" (silent). The fixture shape must come from the scaffold (`sdlc_init.py:243-249`) and `tests/test_doctor.py` `_NS_FULLY_FILLED` (~4280): heading `## Architecture (how it's built + the rules we develop by)` (so the heading regex `^#{1,6}\s+Architecture\b` matches with a trailing parenthetical), then an unnumbered prose paragraph, then `1. <rule>`; scaffold placeholders are `1. <e.g. ...>`. Real adopter shape remains unmeasured (design already lists this as a stated limit). Also AC wording "real file" cannot be met on Sigma itself; the plan should say so rather than fake one.
2. **The "memory-derived read ceiling" helper does not exist in doctor.py.** doctor.py's only read bound is `MAX_STORE_READ = 1 << 20` at 1644, comment "PROVISIONAL", a constant (used at 1652, 1676 for spend store reads). Memory probing lives elsewhere: `skills/sigma-loop/scripts/quality_delta.py` `probe_memory()` (available,total; Linux /proc/meminfo, macOS vm_stat via subprocess, None on failure) and `skills/sigma-loop/scripts/resource_guard.py` (ctypes sysctl sample). AGENTS.md SAFETY says limits are derived, not constants. Plan decision needed: (a) cross-load `quality_delta.probe_memory` via `_load_loop_script` and derive e.g. a small fraction of available memory with a hard floor/clamp, falling back to refusal ("unreadable, cannot derive a limit") when the probe returns None; or (b) honestly reuse `MAX_STORE_READ` while labelling it as a documented provisional constant (weaker; contradicts the design's own wording). Recommend (a), but note `probe_memory` spawns `vm_stat` on macOS (design says no subprocess beyond git rev-parse) - measure cost, or read via `os.sysconf` only. Flag as a design deviation to record in the plan.
3. **Worktree vs main-checkout reads.** `.sdlc/*` is gitignored, so a goal worktree has no `context/` or `decisions.json` (confirmed: `ls .sdlc/work/662/.sdlc/context` fails earlier in design; `.sdlc/context` also absent in root).
