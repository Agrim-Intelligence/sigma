## Goal in one paragraph
Add `brief(sdlc_dir, goal, phase="research", now=None)` and the verb `reuse.py brief <sdlc_dir> <goal> [plan]` to `skills/sigma-loop/scripts/reuse.py`. It prints, as markdown, either the Research brief (Risk line rule, the exact `**Source:**` and `**Searched at:**` lines, graph-mode delta files, the decision ladder, the `## Reuse` and `## Test design` skeletons, the in-flight lines, the `check-research --at-research` command) or the Plan brief (a `## Reuse` bullet per research row id, a `## Test map` bullet per criterion id, the `red_green.py check-tests` command). Output is deterministic, at most 12,000 characters, with no absolute path, and the ladder is generated from `DECISIONS` so the brief cannot disagree with `reuse_errors`. The verb prints text only: no write, no fetch, no new process beyond what `source()`, `inflight()` and one `git rev-parse HEAD` already run. Tests go in a new `tests/test_reuse_brief.py` (16 named tests) plus one CHANGELOG bullet. Part of epic #2276, story #2275. All four blockers (#2279, #2280, #2282, #2283) are merged in this checkout (HEAD `26c6cda`), as are #2281, #2284, #2286, #2287 and #2289. No skill file is edited (the Research and Plan skills get their one-line pointer in a separate ticket).

## Constraints & unknowns
- Unverified: `.sdlc/design/2275.md` was not read; FR-19, FR-20, FR-21 and FR-54 are taken from the issue text.
- Unverified: north-star (`python3 skills/sigma-loop/scripts/north_star.py`) was not consulted; the verb adds no layer and no source of truth (the ladder's single source is `DECISIONS`).
- Unverified: end-to-end cost of `brief` with 50 remote goal branches (the `inflight` ceiling is 120 seconds, stated in #2283, not measured). The PR should say so, and measure after a `git fetch` if branches exist.
- Blocking: none.
- Non-blocking: absolute path in quoted in-flight text. The issue says the output has no absolute path and also says in-flight lines are "printed as they are". A branch can quote `[path]...`. Recommend printing them as they are (the issue's rule) and have the no-absolute-path test use fixtures whose branches contain no path; note the residual in the docstring. Alternative: replace any token starting with `/` in the in-flight block, which departs from "as they are".
- Non-blocking: where the "when each decision applies" wording lives. Recommend a third element in `DECISIONS` over a second dict, since the issue says one structure feeds both.
- Non-blocking: when the 12,000-character budget cuts the in-flight lines, the issue says print the lines that fit, then `... <n> more line(s): run reuse.py inflight .sdlc "<goal>"`. The trailing parts (`Then run:`, the `Plan:` line and the closing sentence) must come after the in-flight block and be reserved before the lines are fitted, or the cut would remove the check command; the issue's ordering (item 8 before 9-11) and this test (`test_research_brief_ends_with_the_check_command`) make that a hard requirement. Plan the budget as fixed parts first, remainder for the lines.
- Non-blocking: `git rev-parse HEAD` runs at `review_tests._root(...)`, which may be a worktree; a root that is not a repository or has no commit must print a placeholder line (and the test-design check will refuse it at `--at-research`), never a traceback. The id read from git is hex-checked (`SEARCHED_AT`) before it is printed; the commit in graph mode used in `git diff --name-only <commit>..HEAD` comes from `source()`, already hex-checked.
- Non-blocking: graph mode lists the delta files; names are untrusted text from `git diff` and are printed on one line each (control characters replaced), sorted as `source()` returns them.
- Control list for the PR, each clause broken alone: the ladder reading `DECISIONS` (change a rule's text, see the names test fail); the fill-and-check test for research and for plan (drop a skeleton line the checker needs); the 50-file delta cap; the `more line(s)` cut and the reserved tail; the byte-identity test (inject a timestamp); the absolute-path test (print the root); the unknown-phase usage clause; the legacy sentence; the no-record placeholder row. Run each on the documented gesture (`python3 skills/sigma-loop/scripts/reuse.py brief .sdlc <goal>`), not only the in-process call.
- Risk: none. It prints text, reads git and committed files, and writes nothing. Other branches' text is untrusted data and the brief says so in a sentence.
