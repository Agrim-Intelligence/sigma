## Helper facts that gate everything
- `read_issue` GH_FIELDS = state, stateReason, author, closedAt, body, labels, assignees, comments. NO `number`, NO `title`
  (`_check_fields` raises ValueError). triage:1549 and brainstorm:178 ask for them -> 2 fields to add (REST has `number`, `title`).
- REST `issues/N` on a MERGED PR, measured live (this repo, PR 928): `state: closed`, `state_reason: null`, `pull_request.merged_at` set.
  `gh issue view` gives `MERGED`. `blocker_scan.closed_state("CLOSED", "")` is False, so a merged PR blocker would read as UNRESOLVED.
  Affects auto_unpark:231, blockers:172, promote:284 (all use `closed_state`). `to_gh_shape` must map `pull_request.merged_at` -> `MERGED` first.
- `list_issues` returns RAW REST dicts (state lowercase, `closed_at`, labels `[{name,...}]`, PRs filtered), not `--json` shape. No
  `closedAt`/`state` upper-casing. REST supports `state=all|closed`, `sort`/`direction`; there is NO `--search`. `_BOARD_ITEM_LIMIT`=5000 -> 50 pages/call at per_page 100.
