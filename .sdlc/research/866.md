## Goal in one paragraph
Create `evals/regression/layer1.py`: for each of two sessions (init, loop) a run directory with a fresh empty profile and a sibling plugin export; a scratch repo cloned from a local bare remote with repo-local git identity; the fake `gh` shim first on PATH with fixed absolute `FAKE_GH_*` paths; run config written into the scratch repo with each written key recorded; a two-session driver that runs init then loop through an "arm" callable; scratch cleanup after rows are copied out; hermetic tests with a fake arm. Offline and model-free. Worktree base: `origin/feature/regression-eval` (HEAD 8ae89660).

## How tests do fake-arm / fake claude
- Pattern A (tests/test_bench_isolation_launcher.py:37-62): a Python script written at test time (`#!__PY__` replaced by sys.executable); first stdin JSON drives it (`write`, `dump`, `exit`, `sleep`); `--version` answers. Reusable for a fake `claude` run via `run_claude`.
- Pattern B (preferred for this goal, per D-8 and AC-5): an in-process FakeArm callable passed to the driver, called as `arm(session_spec) -> Attempt-like` that can write into the scratch repo (e.g. `.sdlc/...`) and inspect the env/profile it was given. No process, no launcher, no spend. A second smoke test may use Pattern A through `run_claude` with a fake launcher shim.
- Regression-test conventions: `ROOT`/importlib-by-path loading; POSIX-only skip marker `posix_only`; env passed as an explicit allowlist (tests/test_regression_live.py:75-88); `tmp` fixtures.

## Risks
- Hidden coupling: BR-4 ledger-test write ratchet and the write-surface ratchet will both fail CI if missed.
- AST pins on live.py: do not touch it.
- Fake-gh extraction from a test file: if that test's constant is renamed, layer1 breaks; add a test that pins the extraction.
- Sibling-of-profile and fresh-profile launcher rules cannot be verified end to end without the operator-installed launcher; hermetic tests copy the rule, so say "not measured against the real launcher" in the README (RELIABILITY).
- Scale/ceiling: one run = two sessions, sequential, scratch is small (export of 3 trees + tiny repo); cost is per session not per repo size. Unbounded growth: scratch dirs from crashed runs - sweep by marker+age (state the lever).
- SAFETY: no credential in config/logs; the arm gets credentials from its caller, layer1 never reads them; POSIX-only (`require_posix`) refuse loudly elsewhere.
- Do not guess #865's answers: every unverified default is emitted in the result as `assumptions`.
