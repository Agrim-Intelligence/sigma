# Research: leak_scan detects a private key anywhere in a line

**Goal**: #449 · **Lane**: medium · **Date**: 2026-10-03

## Goal in one paragraph

Extend the existing `key-body` DER-first-line recogniser so a private-key DER token is found when it is embedded in a JSON string, shell-quoted value, or `key: <base64>` assignment. The recogniser must preserve the current DER discrimination and report the containing line through the documented `python3 tools/leak_scan.py` gesture.
