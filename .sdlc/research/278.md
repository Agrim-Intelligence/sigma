## Defect 1 — walker exemption too broad (conflict_walk.py DONE push)
`walk_conflicts` passed `accepted=[every resolved path]` to `push_branch`. Repro (adv3/test_exempt.py):
main lands 300 lines + a one-line edit in x.txt, branch tweaks that line, main reverts. The replay
conflicts on ONE line; the 300-line removal merges outside the markers. Resolving the one hunk (MANUAL,
or ABANDON = checkout --ours of the whole file) exempted x.txt and the walk force-pushed 40 lines.
Only `action == "removed"` (ABANDON/FOLLOW on a base-deleted file) is a decision to lose the path.
Menu `[3] Abandon this hunk` is false: `_resolve_to_stage(…, 2)` checks out the WHOLE file (or rm).

## Defect 2 — push chokepoint compares only against the remote tip
`push_branch` ran `dropped_paths(<remote>/<branch>, HEAD)`. Repro (adv3/test_localdel.py): a local,
unpushed `git rm old.txt` commit is "lost" relative to the remote → REBASED refused as would-drop,
and the advice `git reset --keep <remote tip>` discards the local commits.
Pre-rebase head sources: `attempt_rebase` has `pre_head`; a stopped rebase has
`<gitdir>/rebase-merge/orig-head` (read before `--continue` finishes, the dir is gone after); after a
rebase finishes the branch reflog's newest entry is `rebase (finish): …` and `<branch>@{1}` is the
pre-rebase head (verified, git 2.55).
