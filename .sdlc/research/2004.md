# Research: #2004 size classifier + per-slice PR soft cap (FR-52, FR-69)

Design: `.sdlc/design/2000.md` (slice 9 row; D-15; "Feature 1, cut"; run-the-control row for the safety net).

## What exists
- Only diff line-count source: `zones._diff_counts(top, fork)` (`skills/sigma-loop/scripts/zones.py:318`): `[(path, added+deleted | "binary")]`, working tree vs fork point, renames keyed on old path, `None` on git failure. `zones._fork_point(top, ref)` gives the merge-base.
- Sensitive path globs: `SENSITIVE_GLOBS` in `risk-detect.sh:132` (bash `case` globs, `*` crosses `/`).
- `work.pr()` (`work.py:4359`) is the PR-open point; its result is a string `PR #N` that callers show; the work record (`_record/_save`) is the place to keep per-PR facts.
- No PR size cap exists (PC-1 falsified). Slice-aware PRs (slice 4+) do not exist yet in this branch, so the cap applies to the PR the goal opens.

## Decisions (smallest reading of FR-52/FR-69/D-15)
- New module `size_class.py`: `classify_files(files, generated_globs, header_of)` and `measure(top, remote, base, cfg)`; classes handwritten, generated_or_mechanical, tests, docs, sensitive. Precedence sensitive > generated > tests > docs > handwritten (a gamed label can only raise scrutiny, never lower it).
- FR-69 (class gaming): tests class needs a TEST PATH (dir `tests|test|__tests__|spec` or `test_*`/`*_test.*`/`*.test.*`/`*.spec.*` basename); generated class needs a configured glob (`work.generated_globs`) or a header marker in the first 5 lines of the file at HEAD (`@generated`, `DO NOT EDIT`, `Code generated`, `auto-generated`). Anything else, however it is named or what it contains, is handwritten.
- Header reads: ONE `git cat-file --batch`, at most 500 files; beyond that, handwritten (fails toward more scrutiny). Cost O(files) in one process; at 100x (50k files) the cap bounds it.
- Binary entries: files counted, 0 lines. Unmeasurable diff (git failure): record nothing, the PR still opens (soft cap is advisory; the fail-closed net is slice 11/FR-55).
- Soft cap: `work.slice_pr_soft_cap` (default 400, D-15 proposed value), counted over handwritten + sensitive lines. Advisory: the `pr` result gains a note; nothing refuses. Counts and the cap flag are stored on the work record as `size`.
- Records the counts (FR-52) in the work record `size` field so slice 11 reads them.

## Blast radius
`work.py:pr` (one added call, fail-open), new `size_class.py`, new test file, docs line in `docs/worktrees-and-merging.md`. Tests that call `pr()` use a fake `run` and a non-git path: measure must return None there and change nothing.
