# Research: #581 signal-seam test under an inherited ignored SIGHUP; review-units tool after install.sh was removed

Phase P2 RESEARCH. Base `c3faf6f23e12` (origin/main). Inputs: issue #581, `.sdlc/acceptance/581.md`, review step S2 (#580).

## Defect 1: the seam test
- `_install_signal_cleanup` (`skills/agrim-loop/scripts/slack_commands_listen.py`) skips a signal whose current disposition is
  `SIG_IGN` (the guard added by #424): a launcher such as `nohup` sets SIGHUP ignored on purpose.
- `test_seam_installs_handlers_that_release_then_die_by_the_same_signal` loops over SIGTERM and SIGHUP and asserts a callable
  handler is installed for each. It never sets the starting disposition, so it passes or fails by what the test process inherited.
- `test_seam_an_inherited_ignored_sighup_stays_ignored` already proves the production guard (sets SIGHUP ignored, asserts it
  stays ignored). It is the control for "do not weaken the guard" and is unchanged.
- Fix is in the test only: set SIGTERM and SIGHUP to the default at the top of the seam test (the existing `_restore_signals`
  fixture puts the inherited dispositions back afterwards).

## Defect 2: the units tool
- `tools/readiness/review_units.py` names 22 paths in `TIER_A_FILES`; `install.sh` was deleted by #408, so `classify` raises
  `UsageError` and the tool exits 2 at any later commit.
- Its docstring states the refusal is intended: skipping a named path would quietly shrink "reviewed in full", and the list is
  tied to the frozen commit. Schema `readiness-units/v1` fixes the key list, so a "dropped" record in the output would need a
  schema change that every consumer and test pins. Decision: keep the refusal as the re-cut lever and document the exact edit
  (delete the path from `TIER_A_FILES`, and from `ISSUE_TIER_A` in the test, in the same change that re-cuts). Apply it now.
- Consequence: the list is 21 paths; a commit from before the deletion would not get install.sh in its Tier A (stated in the
  docstring). Tests and pages that pin 22, the old frozen sha or the old counts must move with the re-cut:
  `tests/test_readiness_review_units.py`, `tests/test_review_plan.py` (ceiling recompute reads the committed units),
  `tests/test_mechanical_gates_evidence.py` (compares the old units file to the evidence), `docs/launch/seeded-defects.md`,
  `docs/launch/review-plan.md`.
