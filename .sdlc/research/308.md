# #308 research -- #233 review follow-ups: repo rename, old setup_created marker, Phase-field race

**Size: small.** Three files of code (`sources.py`, `board_setup.py`, `tests/boardfake.py`), two test files, docs + CHANGELOG.

## 1. Repo rename (`sources._load_items`, #233)
- `_load_items` skipped every `item-list` row whose `content.repository` != `discovery.github.repo` (casefolded).
- Measured read-only on github.com with a known renamed repo (`twitter/bootstrap` -> `twbs/bootstrap`), `.sdlc/evidence/308/00-live-readonly-rename-resolution.txt`:
  REST `repos/<old>` -> current `full_name`; GraphQL `repository(owner,name)` resolves the old name too;
  `resource(url:)` for an OLD-name issue URL is **null**, for the new-name URL it is an Issue.
- Consequence: stale config after a rename -> every card looks uncarded -> `_sync_backlog` -> `_item_id` -> `item-add --url <old>` fails
  on real GitHub (board mirroring stops; one warning). If it resolved, item-add returns the existing card, `was_new=True`, and the seed
  write resets In Progress/Blocked to Ready (reproduced on the fake with `old_urls_resolve=True`).
- Phase path (`_read_card`) is repo-scoped by GraphQL `repository()`, which resolves renames: not affected.
- Reviewer repro `rvF233/t_rename.py` imports from the deleted work/233 worktree; rebuilt as two tests.

## 2. Old bare-number `setup_created`
- `board_setup.pin(created=False)` deletes any marker `_ours` does not vouch for; the bare int never passes -> docs' "until create re-pins it" was false.
- The proposed upgrade was rejected in review: an old owner change or hand edit could leave a bare marker beside an unrelated owner. The final code drops it and never upgrades it; `create` treats the board as adopted and adds no Ready lane.
- Recovery correction (#317): `create` without `--number` still falls back to `project.number`. Keep the existing board via `mirror_priority: true`, or remove the pin and choose an unused title to create a separate board. Existing cards do not migrate.

## 3. Phase-field race
- `set_board_phase`: read card (no Phase) -> `createProjectV2Field`. Two concurrent first starts: the fake refuses the second
  ("Name has already been taken"); the loser warned and `_write_board_phase` found no field -> Phase not written. Live GitHub duplicate-name
  behaviour not measured (no mutation allowed).
