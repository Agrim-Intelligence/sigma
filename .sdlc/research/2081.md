# Research: Ledger publish from a cloud run: concurrent publishers in one worktree, in-process outcomes never flushed, container id follows TMPDIR
**Goal**: #2081 · **Lane**: medium · **Date**: 2026-10-28

Code read in the goal worktree `<repo>/.sdlc/work/2081` (branch `sdlc/2081`, at `0c75756`, Sigma 1.0.23, which contains #2076/#2082). Acceptance is `<repo>/.sdlc/acceptance/2081.md` (AC-1..AC-4), not edited. Nothing in the worktree was changed (`git status --short` was empty before and after).

## Goal in one paragraph
#2076 made the loop publish its own ledger entries (`sync.publish_entry`) so a cloud container's claim, keep-alive and outcome reach origin without a daemon. The independent review left four gaps: (1) several processes publish into ONE ledger worktree with no mutual exclusion, and `_abort_stale_rebase` cannot tell a killed rebase from another process's live one; (2) entries recorded in-process by something other than `loop.main` are never flushed; (3) the container id (and so the host token in the writer identity) follows `TMPDIR`, so one container can carry two writers and the holder's own `lease-renew` fails the same-host test; (4) the jitter pause is not capped by the remaining deadline. Close 1-3, and 4 if free; each shown red first on the gesture the docs give (AC-4).

## Constraints & unknowns
- **Measured, with commands (scratch harnesses live in `<scratchpad>/`, outside the repo):**
  - Gap 3 primitive: `CLAUDE_CODE_REMOTE=true TMPDIR=<scratch>/tmpA python3 -c "...ledger._host_token({})"` gives `ea3cc696`; the same with `TMPDIR=<scratch>/tmpB` gives `b9991805`. One machine, two tokens. `env TMPDIR=/nonexistent python3 -c "import tempfile; print(tempfile.gettempdir())"` prints `/tmp`, `env -u TMPDIR` prints `/tmp`: an unusable TMPDIR falls back to `/tmp`, a usable one wins.
  - Gap 3, lease-renew: claim written under `TMPDIR=tmpA` five hours ago (`repro3.py claim`); `repro3.py renew` from `tmpA` writes `dana:ea3cc696.72236:1`; from `tmpB` returns `None` (no renewal, the claim would lapse at the 12 h TTL).
