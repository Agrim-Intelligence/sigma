## Goal in one paragraph
Add `inflight(sdlc_dir, goal, remote=None, base=None, run=None, now=None)` and a `reuse.py inflight <sdlc_dir> <goal> [--remote N] [--base R]` verb to `skills/sigma-loop/scripts/reuse.py`. It lists the remote-tracking goal branches (`refs/remotes/<remote>/<prefix>`, newest first, at most `MAX_BRANCHES = 50`), skips the goal's own branch, and for each other branch diffs it against the base (`git diff --name-only <base>...<branch>`, three dots), runs every recorded query with `git_grep` over only the changed files (at most `MAX_CHANGED_FILES = 200`), prints `INFLIGHT` hits, and prints `DECLARED` for every `extend`, `dependency-new` or `new` table row in a changed research dossier or plan (size-checked with `git cat-file -s` before `git show`). The last line says how many of how many branches were searched and the fetch age; the whole run stops after `MAX_SECONDS = 120`. `check-research --at-research` then prints these lines under `In-flight work:` without changing its exit code. No network. Tests go in a new `tests/test_reuse_inflight.py` (about 20 named tests), plus one CHANGELOG bullet. Part of epic #2276, story #2275; blocked by #2281 (merged).

- Unverified: north-star (`python3 skills/sigma-loop/scripts/north_star.py`) was not consulted; no new layer or source of truth.
- Blocking: none.
- Non-blocking: the brief says not to load `work.py`, but the required shared `base_ref` already does. Recommend keeping `base_ref` shared (as the brief insists) and reading only the own-branch record directly.
- Non-blocking: the brief names one injected clock, `now`; `rerun` has `clock` (deadline) and `now` (wall time). Recommend `inflight(..., run=None, now=None, clock=time.monotonic)` with `now` as the wall clock for `fetch_age` and the clock test stub supplying the deadline, which keeps the brief's signature as a prefix.
- Non-blocking: `fetch_age` takes the newer of the worktree and common-dir `FETCH_HEAD`; the brief says common-dir only. Recommend the existing function (it was measured in #2281).
- Non-blocking: `--remote` with a base from the work record: recommend prefixing `--base` with the chosen remote and otherwise leaving `base_ref`'s result.
- Non-blocking: control list for the PR, each clause broken alone: own-branch skip; the cap; three dots vs two; the `new`/`extend`/`dependency-new` filter and the `reuse`-row exclusion each separately; the size check; the one-line cut and the 200-character cut separately; the time limit; the no-network guard; and, for `--at-research`, the exit-code clause (in-flight lines never change it) on both a passing and a failing dossier. Run the control on the gesture the docs give (`reuse.py check-research .sdlc <goal> --at-research`), not only the in-process call.
- Non-blocking: the sensitivity of the clock-limit test: an injected clock that jumps past 120 seconds after the first branch is deterministic; no race test is involved.
- Risk: none. Reads git refs and committed files only; no write, no network, no auth or PII, no migration. Branch contents are untrusted: each branch ref is resolved to a commit id before use, paths are never trusted as options (`--literal-pathspecs` via `git_grep`), and quoted text is printed on one line cut to 200 characters.
