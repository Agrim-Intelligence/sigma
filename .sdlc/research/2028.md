# Research: Compaction safety net: daemon sets the compact window; rules and live slots re-injected after compaction
**Goal**: #2028 (slice 3 of Epic #2025, design `.sdlc/design/2024.md` §3, BR-9, BR-10, BR-17) · **Lane**: medium · **Date**: 2026-10-24

## Goal in one paragraph
Two independent safety nets beside slice 2's context hand-off. (1) Both Claude launchers, the
supervisor daemon and `autowatch.py`'s drive, put `CLAUDE_CODE_AUTO_COMPACT_WINDOW` into the
child's env dict, never into `os.environ`, and only when the operator has not set the window
themselves. The value comes from `handoff.after_context_tokens` when set; otherwise it is a
stated default. It sits above the hand-off point, inside the documented 100000..1000000 range.
Codex children stay as they are. (2) `hooks/session_start.sh` reads its stdin. On `source:
compact` only, it emits Sigma's standing-rules brief plus the `log.py slots` block as
additionalContext, before every `SIGMA_RUN_ID` gate and inside its 20 s timeout. Every other
source behaves byte-for-byte as before.

## Constraints & unknowns
- Unverified: whether a `CLAUDE_CODE_AUTO_COMPACT_WINDOW` set inside a settings file's `env` block outranks a process env var. A substring check of the settings files for `CLAUDE_CODE_AUTO_COMPACT_WINDOW` treats it as operator-set either way, which is the safe direction.
- Unverified and undetectable: a window set by **managed** settings (MDM, server-managed, the embedding host). The process env var outranks those too, per the docs. This slice can only read files; it cannot read MDM or server policy. State it as a limit in the docstring.
- Unmeasured: a live compaction in a real `claude -p` run. The hook branch is tested with a payload, not against the host.
- Blocking: none. The window derivation with `after_context_tokens` absent is a planning decision (see the plan), not a conflict.
- Non-blocking: the compact tier fires on any adopted repo (`.sdlc/config.json` exists), not only under `session_start.enabled`. That adds about 600 tokens after a compaction. Decision for the plan reviewer.
- Non-blocking: if slice 2's derived threshold ends up above this slice's default window (500,000), the host compacts before the hand-off fires. Slice 2's D-1 range (2-4× a 70-100k start, so at most 400k) keeps it below. Flag it on #2027.
- North-star: `north_star.py` → `absent` (a drop-in project, so this check is skipped).
- Conditional review: no auth, no migration. The env var is a host contract we write, so a light `/sigma-contract-check` on the env-var surface is optional.

## Lane rationale
Medium: about 4 production files across 3 modules (daemon, autowatch, hook) plus 1 new 1-function
module. It adds one cross-module rule (shared by two launchers) and no new source of truth (it
reads one config key slice 2 owns). There are 2 doc rows, and 5 test files are touched. It crosses
the host contract (env var, hook stdin), which is beyond small. It adds no new boundary, so it is
not large.
