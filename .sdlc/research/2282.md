## Goal in one paragraph
Add `check_plan(sdlc_dir, goal, plan=None)` returning `(errors, warnings)` and a `reuse.py check-plan <sdlc_dir> <goal>` verb to `skills/sigma-loop/scripts/reuse.py`. For a new-format dossier it first reports every `check_research` error, then requires the plan to carry `## Reuse` (one `- RU-<n>:` bullet per dossier row id, optional table obeying the row rules with no id collision, or `none:` when the dossier says `none:`) and `## Test map` (exactly one `- AC-<n>:` bullet per recorded criterion; values are covered tests, `UNTESTABLE: <why>`, never `NONE`; docs-only plans may map `none: <reason>`). Legacy goals are a warning. Tests go in a new `tests/test_reuse_plan.py` (24 named tests), plus one CHANGELOG bullet. Not wired into any gate. Part of epic #2276, story #2275; blocked by #2279 and #2280, both merged. `.sdlc/design/2275.md` is not in this checkout.

## Test design
| Criterion | Behaviour | Failure path | Hostile input | Helpers |
| --- | --- | --- | --- | --- |
| AC-1 | plan `## Reuse` must hold one RU bullet per research row id | a missing bullet is refused and the id named | n/a | _project, _dossier |
| AC-2 | `## Test map` holds one AC bullet per criterion; docs-only plan may map `none:` | a missing or duplicate bullet is refused and the id named | n/a | _project, ACCEPTANCE |
| AC-3 | NONE, empty UNTESTABLE and uncovered tests are refused naming the criterion | a test not in `## Tests` is refused | a runner bullet with a lookalike prefix is not covered | _project |
| AC-4 | no dossier or legacy dossier exits 0 with a stderr warning | none: legacy is a warning by definition of the rule | n/a | _project, _dossier |
| AC-5 | plan table rows obey the row rules; an id colliding with research is refused | a malformed row is refused naming the row | n/a | _dossier |
| AC-6 | every check_research error is reported unchanged | a dossier with no Test design fails the plan check | n/a | _dossier |
| AC-7 | no acceptance record is an error when enforced and a warning when not | the Test map is skipped on warning | n/a | _no_record |
