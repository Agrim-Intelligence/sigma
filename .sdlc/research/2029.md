# Research: Host-neutral successor brief at hand-off, a read-only meter verb, and the attended desktop supervisor pattern
**Goal**: #2029 (slice 4 of Epic #2025, design `.sdlc/design/2024.md` §4, FR-7) · **Lane**: medium · **Date**: 2026-10-24

## Goal in one paragraph
When `loop.py next`/`next-batch` returns `HANDOFF`, code (not the orchestrator's prose) prints one
successor brief on stderr, built from local files and the call's own argv: the resume command with
this run's `--feature`/`--label`, the live slots (the constructed Block A from `log.py slots`), and
the open decisions. Stdout stays the bare `HANDOFF` token. A new read-only verb prints the calling
session's own context reading (slice 1's `context_reading()`), its threshold and its source,
without picking, claiming or writing, so an attended desktop supervisor session can decide when to
replace itself. The skill and docs describe the three host paths and the no-wake-up rules.
Base: worktree `sdlc/2029` cut from `origin/main` at `504de5c1`; slice 1 (#2026, PR #2031, head
`a69692da`) is approved, not merged, and is read from `.sdlc/work/2026`.

## Constraints & unknowns
- Output contract: the brief is plain stderr text (no marker, no emoji, no `##`); its live-slot
  part is `log.py slots` output, which is a constructed Block A, embedded verbatim. Stdout stays the
  bare token — three consumers match it as an exact line (`supervise_classify.py:85-88`,
  `chain.py:1464`, `:1485`).
- The fixed brief text must not match `_DONE`, `_DONE_DEGRADED`, `_LIMIT`, `_HOLD` or `_BUDGET`,
  all checked before `_HANDOFF` (`supervise_classify.py:150-170`).
- Phase-context ratchet: 22 est-token headroom on the orchestrator set; slice 2 edits the same
  files in parallel, so this slice should net-shrink, never spend.
- M6: a subagent's shell inherits the parent's `CLAUDE_CODE_SESSION_ID`; nothing in the env tells
  a subagent from its parent, so "top-level only" is a documented rule, not a check.
- Unverified: the desktop app's one-click proposal-card behaviour is from Omega's transcript
  (10 launch attempts, one refusal), not re-measured here.
- North-star: `north_star.py` → `absent`; skipped.
- Non-blocking (for the plan): threshold source. Slice 2 owns the resolver; if #2027 has not merged
  when this is implemented, the verb prints `threshold none` rather than a second resolver.
- Non-blocking: github-mode open decisions have no local file; the brief names the `sdlc:parked`
  label instead of making a network read at a stop.
- Blocking: none.
