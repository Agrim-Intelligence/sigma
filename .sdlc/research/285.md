## 6. Risks against the five properties, and recommended adaptations
1. **SAFETY / leak (measured).** `_run_gh` raises `RuntimeError("gh <argv> failed: <stderr>")` with `.hint` = gh's stderr alone. Upstream formats `%s` of the exception, so the audit-comment line embeds the whole
   `--body`: `note` + free-text `reason` (work.py passes a stale-resume diagnosis). Measured with a fake gh, a 7-line reason: the "one line" became 8 lines/823 chars, and the stored warning is 667 chars.
   The body is already posted to the issue by that call, so it is no new audience, but AGENTS.md says secrets never enter logs, and whether a reason can carry a credential (e.g. a git URL) is not verified.
   **Adapt:** use `getattr(exc, "hint", None) or exc` (the `_warn_field` precedent, sources.py:4809), collapse whitespace, cap ~200 chars. The ported tests still pass (their double raises a plain RuntimeError).
2. **RELIABILITY.** Return contract unchanged; both failures still fail open. The warnings are an unconsumed getter: the stderr line is the only surface today. The probe failure and `_set_board_status` stay silent (out of scope).
3. **SCALABILITY.** State is at most 2 short strings per call, reset each call, per-process instance, no threads in loop.py/sources.py/work.py. A gh outage over N stale goals costs 2N stderr lines per sweep (linear; capped line size makes it bounded). `release_warnings()` returns the live list: return a copy.
4. **RESILIENCY.** Unchanged lever: re-running `loop.py release` is idempotent apart from a possible duplicate audit comment. The ledger `release` entry is written even when the label stayed attached (`_release` is unconditional), so the divergence is now visible on stderr but not self-healed.
5. **LIVENESS.** Nothing background is added; the one new signal is a stderr line at the moment of failure, with no age or heartbeat semantics.
6. **Guard gap (upstream design):** `--for pr-review --output X` with NO `--artifact` still writes an unbound manifest, rc 0 (measured). The goal says "non-empty artifact", so this port keeps it.
