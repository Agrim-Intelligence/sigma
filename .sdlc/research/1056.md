## Minimal design
- `mutators.apply(regression, form, root) -> list[str]` (changed repo-relative paths). Errors: `class MutatorError(Exception)` with `.code`
  and `.kind` (`anchor-missing` 10, `anchor-ambiguous` 11, `mutation-noop` 12). CLI `apply <regression> --form <form> --root <dir>`
  prints changed paths on stdout, `mutators.py: <kind>: <detail>` on stderr, exits with the code; `anchors` prints one line per
  `regression form file::symbol[#entry]`. Usage errors (unknown regression/form) exit 2 via argparse/explicit; no config read.
- Table `MUTATORS = {regression: {form: (file, symbol, kind, ...)}}`: kinds `body` (replace function body after docstring with a
  return line), `value` (replace assignment RHS), `drop-element` (delete one Tuple child of the named assignment, matched by its
  first Constant string), `append-words` (double-context). Replace the node's line span (lineno..end_lineno) and keep the
  rest of the file byte-for-byte. Write back only if the text differs, else 12.
- Forms: skip-plan-review: `code`; drop-review-recording: `code`; disable-secret-scan: form IS the variant
  (`drop-pattern`, `drop-redactor-only`, `whole-table`, `commit-noop`); double-context: `words`. Prose form is not registered (pending on 805's cards, D-2).
- double-context: run `<root>/evals/phase_context_budget.py --json` with cwd=root; pick the first phase (JSON order, sorted) whose files are
  all real paths (no `rendered:` label), e.g. `research`; append that phase's `words` of filler ("context" repeated) to `files[0]`. A failed or non-JSON run
  is `anchor-missing`. 0 words is `mutation-noop`. Doubling one phase puts it over its ceiling, so the gate exits 1. Files shared across phases also raise
  the others; acceptable.
- Rename hint: on 10, run `git -C <root> diff HEAD --unified=0 -- <file>`; collect removed `def NAME` and `NAME =` lines (regex on `^-`) and print
  them as `candidates:`. Best-effort: not a git repo or empty diff means no candidates. ponytail ceiling: after commit the diff vs HEAD is empty,
  so the hint only helps for an uncommitted rename; the CI/PR form can pass a base later. The `previously:` names are slice 2's data concern.
- Edit whole lines only (`splitlines(keepends=True)`, node lineno..end_lineno); every anchor starts its own line.
