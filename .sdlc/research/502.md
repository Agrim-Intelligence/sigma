# Research: #502 — exact paired test for the 15-task benchmark

Blast radius (searched `git grep` on origin/main `53f8120`): the old threshold ("lower 95% CI bound at least -5 points",
10,000 resamples, seed 20261001, "−5 points") appears only in `docs/bench/preregistration.md` and the assertions of
`tests/test_bench_preregistration.py`. `evals/README.md` links the document without quoting the threshold. `evals/bench/`
holds `bench.py` and `meter.py`; neither computes a statistic, so no code consumed the bootstrap.

Design facts: 3 arms (A1 Sigma, A2 plain agent, A3 matched-spend), about 15 tasks, one repeat, hidden-test pass is 0/1.
Each comparison A1 vs B therefore yields W (A1 pass, B fail), L (B pass, A1 fail), T (ties). Ties carry no information
about direction. Conditional on D = W + L, W ~ Binomial(D, p) with p = pw/(pw+pl); p <= 1/2 iff Sigma is no better.

Candidates computed (prototype, stdlib, exact rationals; the shipped script re-derives them):
1. Conditional exact one-sided sign test on D. Valid for any discordant rate. At alpha 0.05 it can pass only if
   D >= 5, and the fewest net wins that pass is 5 (5 of 5). Worst-case wrong-GO at a true tie, n = 15: 0.030.
   P(GO), n = 15, d = 40%: +20 points 0.176, +30 points 0.410, +40 points 0.783.
2. Non-inferiority with a margin in whole tasks, unconditional test "W - L >= c", size maximised over the discordant
   rate on a grid: margin 1 task (6.7 points) needs net wins >= 6 at alpha 0.05, margin 2 tasks needs >= 6, margin 3
   tasks (20 points) needs >= 4. Non-inferiority at this n costs superiority-grade evidence unless the margin is 20
   points, which is too loose to call non-inferior.
3. A margin floor on top of the sign test ("also W - L >= m"): never binds for m <= 5 at alpha 0.05, so it would be
   decoration. Not adopted.
4. A harm-only screen (GO unless Sigma is significantly worse): reachable, but it cannot show anything; with 15 tasks
   it declares GO against a truly worse Sigma most of the time. Rejected as a launch criterion; recorded.

Multiplicity: GO is a conjunction over two arms, an intersection-union test, size <= alpha with no correction and no
assumption about the dependence between arms; its joint power is bounded by the Frechet limits. NO-GO is a union, so a
false NO-GO is bounded by 2 alpha.

Conclusion for the document: type-I control is easy and exact; power is the constraint. No rule at this size gives
useful power for a moderate real advantage, and no non-inferiority claim is available. State that plainly, define
INCONCLUSIVE, and keep alpha, the margin and the arm structure as owner decisions with recommendations.
Constraints: no new dependency; the script writes only to stdout (write-surface inventory); the doc and tests must
not name predecessor names; the doc may name `evals/bench/decision_rule.py` (the public tree already carries
`evals/bench/`).
