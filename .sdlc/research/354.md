# Research: #354 benchmark arms and isolation (reduced three-arm design)

Source of truth: `docs/bench/preregistration.md` on origin/main (amended by #494, #502). Arms: A1 Sigma
(clean `git archive` export), A2 plain agent, A3 matched-spend. The predecessor arm is dropped; no
predecessor option or path is built. In the issue body, A4 reads as A1 and A5 as A3; its A3 (predecessor) is dropped.

## Blast radius
- `evals/bench/bench.py` (364 lines): `Arm`, `ArmRun`, `FakeArm`, `run_benchmark`, `main`. Already requires
  `--hidden-root` and `--isolation-launcher`, refuses CI/background, refuses hidden root inside the repository
  or a task source, and refuses every in-process `Arm` except the exact `FakeArm` (`_run_arm`).
- `evals/bench/meter.py`: `session_paths` + `meter_transcripts` price a session id; reusable for per-attempt cost.
- `tests/test_benchmark_harness.py` pins refusal of untrusted `Arm` subclasses and the fake-arm smoke; it
  neither pins arm names nor counts, so nothing to renumber. `tests/test_bench_meter.py` pins no arm names.
- `docs/launch/write-surface.json` inventories bench.py write sites; new fs write/rmtree sites need entries.
- `evals/README.md` says all live arms are refused; that paragraph must change.

## Findings that shape the design
1. The landed harness deliberately refuses live arms until an enforceable boundary exists. The new arms run
   `claude -p` only THROUGH the operator launcher (`launcher -- argv`), the seam the launcher validation and the
   test launcher were built for. Sigma still cannot prove the launcher contains an agent; the README says so.
2. Scoring order in `run_benchmark` is task, repeat, arm, so A1's per-task spend is known before A3 runs. A3 with no
   A1 spend for the task is a skipped row, not a guess.
3. Hidden-root refusals today cover repository and task-source overlap; a hidden root inside the scratch root
   (where every arm workdir and the plugin export live) is NOT refused. Add it.
4. `~/.claude/plugins` of the operator is hashed before and after each run; any change aborts the whole
   benchmark, keeping the rows already paid for in a results file marked aborted. Tests set HOME to a temp dir.
5. The export is `.claude-plugin`, `skills`, `hooks` of a pinned commit via `git archive`; none of these trees
   contains `tests` or `evals` directories today.
6. Unrelated defect hit: `acceptance.py record` raises (instead of falling back to `--draft`) when the body's
   Done-when has a wrapped bullet.

## Size and lane
Medium: one harness module extension, one new package of three small modules, one test file, README, inventory.
No cost claims: nothing here runs a model; all behaviour is checked against a fake `claude` executable.
