## gh auth status shapes (gh 2.98 measured on this machine; older shapes from gh's history)

- classic/OAuth: `  - Token scopes: 'gist', 'project', 'read:org', 'repo', 'workflow'` (quoted,
  newer gh) or `✓ Token scopes: gist, read:org, repo` (older gh). Token printed masked (`gho_***`).
- fine-grained PAT (`github_pat_`) and app tokens (`ghs_`) send no X-OAuth-Scopes header: gh prints
  `Token scopes: none` or no scopes line. That is "cannot verify", never a pass.
- not logged in: `You are not logged into any GitHub hosts...`, exit 1. Invalid token: `X Failed to
  log in ... token ... is invalid`, exit 1.
- Scope implication: `admin:org`/`write:org` imply `read:org`; `project` needed for board writes
  (`read:project` is not enough); `repo` and `workflow` stand alone.

## Constraints

- Stdlib only; every subprocess timed out and tree-killed (git ls-remote can spawn ssh that holds the
  pipe — `run_with_timeout.py` measured this exact hang). Bound derived from the existing
  `SIGMA_WATCH_CALL_TIMEOUT` convention (default 120s), overridable by `SIGMA_PREFLIGHT_TIMEOUT`.
- Portable: `shutil.which`, no shell, `GIT_TERMINAL_PROMPT=0` / `GH_PROMPT_DISABLED=1` so nothing
  waits on a prompt. Never pass `--show-token`; never print raw `gh auth status` text.
- Host-agnostic: Codex/Cursor have no interactive question and no hook — init prints the decision and
  the exact config line; Claude Code's SKILL.md asks (convention set by #228).
- Parallel goal #230 edits setup.py/sources.py/loop.py start: keep this goal's edits in a new module
  plus small, separate blocks.
