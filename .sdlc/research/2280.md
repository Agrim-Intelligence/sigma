## Goal in one paragraph
Add a `source(sdlc_dir, run=None)` function, a `source_line(result)` formatter and a `reuse.py source <sdlc_dir>` verb to `skills/sigma-loop/scripts/reuse.py`. It reads `kg.py freshness` through a subprocess and answers "graph or grep" with a reason. It also makes `check_research` check the `**Source:**` line: a form check on every run, and, with `--at-research`, an ancestor rule against the searched-at commit and an agreement rule against the live `source()` mode. New tests go in `tests/test_reuse_source.py`, one CHANGELOG bullet, and a measured timing in the PR. Part of epic #2276, story #2275; blocked by #2277 and #2278, both merged. `.sdlc/design/2275.md` does not exist in this checkout (see Constraints).

- Brief amendments the plan should apply (not blocking):
  - `git rev-parse` style trust rule: the commit read from `kg.py`'s stdout must match `SEARCHED_AT` (`reuse.py:44`, 40 or 64 hex) before any git call, and the diff goes behind `--end-of-options` (as `kg.py:722` does), even though the brief's command omits it.
  - A bool `changed_files` (JSON `true`) is not "a number".
  - `holds_code` gate is `is True`, not truthiness.
  - The default `run` must pass `capture_output=True, text=True, timeout=60` for the kg call; a timeout is `subprocess.TimeoutExpired` (reason "knowledge graph helper unavailable"), as are `OSError` and bad JSON.
  - `--at-research` Source rules need `root` and the searched-at commit; if `searched_at` is missing or not full hex, skip the ancestor rule (that error already exists) instead of crashing; `merge-base --is-ancestor` on a commit absent from the machine returns 128: treat as an error "is not an ancestor", not as success.
  - The brief's `graph@<7 to 64 hex>` form means a 7-character abbreviation is accepted by form; the `--at-research` check resolves it with `git rev-parse --verify --end-of-options <x>^{commit}`. An ambiguous or unknown prefix gives a non-zero exit: that must be one error, not a traceback.
- Blocking: none. Nothing in the code contradicts the brief in a way that stops planning.
- Non-blocking: should the three existing tests in `tests/test_reuse.py` (BR-6) be updated to expect the new Source error, or be given a valid Source? Recommend: keep their intent (legacy-vs-new-format marker, missing searched-at) by asserting the exact new list.
- Non-blocking: control list for the PR (one break per rule and per clause: each condition-table row, the 500 boundary `<=` vs `<`, the 7-to-64 form, grep-vs-graph disagreement in both directions, the prefix mismatch, the "ancestor of searched-at, not HEAD" clause). Control for the flag gate: delete `at_research` from the condition and see `test_without_at_research_*` red.
- Risk: none (no auth/PII, public contract of other skills, or migration). `reuse.py`'s command line gains a verb; `check-research`'s exit codes are unchanged.
