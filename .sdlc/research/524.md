## What an old install looks like to the doctor
Claude: `installed_plugins.json` holds `plugins["<name>@<marketplace>"] = [ {scope, version, projectPath?}, ... ]`;
`claude plugin list --json` returns `{id, version}` rows. Codex: `codex plugin list --json` -> `installed[]` with `pluginId`.
An old install keeps working and silently stops receiving updates (the update key changes), so the doctor is the only signal.
