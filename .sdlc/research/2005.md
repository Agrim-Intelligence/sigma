## 2. The budget gate — how it measures, baseline

- Measurer: `evals/phase_context_budget.py`. `PHASES` dict (`:36-84`) maps each phase to explicit files
  (+ an optional rendered `review_context.brief` against `examples/hello-sdlc`, `:103-114`). Words =
  `len(text.split())`; tokens = `skill_structure.estimate_tokens` = `ceil(len(text)/4)`
  (`evals/skill_structure.py:102,133-136`).
- Ceilings: `evals/phase_context_budget.json` (`phases.<name>.ceiling.{words,est_tokens}`, plus
  `measured_at`, `commit`). Gate `findings()` (`:139-170`): fails if measured > ceiling **or ceiling > 1.05 x
  measured** (MAX_HEADROOM `:33`) or the phase set differs from `PHASES`. So any deletion >5% of a phase
  **forces** lowering that ceiling in the same change (implement 431/3050 = 14% -> must lower).
- Adding `test-review-pre`: add to `PHASES`, add a ceiling row to the JSON, and update the hard-coded set in
  `tests/test_phase_context_budget.py:34-37`. Command: `python3 evals/phase_context_budget.py` (also `--json`,
  `--table`); `tests/test_regression_control.py:250` pins that argv.

   stays guarded.

   (regex + execution); "note" gesture and Regen/Disposition text go to a linked reference. The design's
   "if slice 3 confirms the reviewer agent does not need it": §5 is about the *planner's* revision loop, not
   the reviewer's verdict (`§Verdict` `:110-146` stays) — record that confirmation in the plan.
5. Structure-only guarantee: the budget proves bytes, not that an agent runs `next-step`
   (`skill_structure.STRUCTURE_ONLY_NOTICE`). Say so; do not claim behavioural effect.
6. `test-review-pre` payload choice is undefined by the design; pick the smallest real file list and record it
