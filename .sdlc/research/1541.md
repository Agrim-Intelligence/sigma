Record on this goal: `.sdlc/state/work/1541.json` (branch `sdlc/1541`, base `feature/design-fit-by-zone`). Config and `.sdlc` come from the COMMON root via `north_star.project_root`, so read the acceptance file at `<root>/.sdlc/acceptance/<n>.md` the same way.

**Acceptance read.** `acceptance.read(sdlc, goal)` (`:84`) does path-safety (`unsafe_goal_reason`), a 32 KiB bound, and validates; absent raises `FileNotFoundError`, invalid raises `ValueError`. Both map to `intent: unknown`. Load via `_load("acceptance")`; it loads `state` itself.

**Counting lines (measured here).** `git diff --numstat -z --no-renames <fork>` compares fork to the WORKING TREE, so it sees uncommitted edits (the loop commits once at the end); untracked new files are absent, which is right because new is never restructure. Entries are `added<TAB>deleted<TAB>path\0`. Binary prints `-` `-`: treat as restructure (cannot be size-checked), print `binary`. Mode-only change is `0 0`: zero lines. Deleted file: counts its removed lines and is still existing+legacy. `--no-renames` makes a rename a delete (old path, counted) plus an add (new, ignored): conservative, state it in the doc. One run measured: 1,474 entries in 0.43 s wall (314-commit repo, git 2.x); a real large repo is unmeasured. `GIT_TIMEOUT` is 10 s (`zones.py:39`); timeout or rc not 0 means `unknown`, never `within`.

**What `--plan` parses.** The plan format is free prose: sigma-plan SKILL.md prescribes no file-list syntax; `.sdlc/plans/1540.md:5-12` uses a `## Files` section of bullets like `- NEW \`path\`` / `- EDIT \`path\``. Define: read the file (bounded, 256 KiB), take the `## Files` section (to the next `## `), take every backtick span in its bullets that has no whitespace, normalise with `_normalise` (spans that fail normalisation are skipped, not refused: prose backticks like `design.zones` are not paths), then classify by fork state: existing+legacy = modified. NEW/EDIT words are ignored (an existing path named under NEW is still modified). No `## Files` section, or no span resolving to a path = `verdict: unknown`. Unreadable, missing or oversize plan file = refusal exit 2. Directories (tree entries) must not count: `_newness` does not tell blob from tree, so filter or extend it.

## (4) Edge cases and proposed rules
- **Intent match**: candidate tokens are backtick spans plus bare whitespace tokens containing `/`, with surrounding punctuation stripped, a leading `./` and trailing `/` removed. Token T gives intent for file F iff F == T or F starts with T + `/` (component boundary, never substring, case-sensitive, no globs, literal `*` never matches). Ignore `.`, `/`, empty, absolute and any `..` token (no repo-wide intent by accident). A single-component directory needs a backtick or trailing `/`.
- A criterion naming several paths: each token counts independently. Only the `## Done when` criteria are read (`criteria()` skips fenced blocks).
- **Drafted**: counts as intent only when the record is positively marked not drafted. Recommended: `record` writes `drafted: true|false`; `parse` returns it; absent key (every record written so far, including 1541's own) or true = `intent: unknown`/no intent, never yes.
- No `## Done when`, malformed or oversize record: `intent: unknown`, verdict never within.
- No work record or base unresolvable: files print state unknown; verdict `unknown`. Config unreachable: `unknown`.
- `design.restructure_lines`: int, not bool, >= 0; else refusal naming the key. 40 lines = not restructure, 41 = restructure; zero changed lines = within.
- New files never restructure; modern and undeclared never over; legacy existing but deleted counts as above; tracked symlink is a file counted by its own diff (git stores a link target line); submodule/gitlink path is unknown.
- Verdict: any over wins; else any unknown yields `unknown`; else `within`. Absent acceptance record always gives `unknown` (AC-4 read literally).
- Path forms in diff output are git-relative already; `--plan` spans go through `_normalise`. Non-UTF-8 paths survive via `-z`.
