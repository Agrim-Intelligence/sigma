## Constraints

- Host-agnostic: the flow is Python; Claude Code asks questions, Codex/Cursor get the same flow via flags
  and printed `[ask]` lines. No hook is load-bearing.
- Safety: board creation, ledger (spawns the watcher, pushes an ops branch), work.enabled flip, and verify
  command are never defaulted by `--yes`. No real GitHub in tests (PATH fake `gh`, conftest guard).
- A GitHub-origin test must not reach the network: `git ls-remote` against `https://github.com/...` is
  blocked with `GIT_ALLOW_PROTOCOL=file` (preflight then reports base as CANNOT VERIFY); pushes are
  redirected to a local bare repo with `url.<bare>.pushInsteadOf` (get-url still shows the GitHub URL,
  which mode detection needs).
