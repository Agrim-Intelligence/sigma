# Research: #523 — rename skills and commands from the company prefix to `sigma-`

Measured on a throwaway clone of main at a3c913c (not the goal worktree).

## Footprint (measured)
- 560 tracked files of 798 contain the old prefix; 5,399 lines. 242 tracked paths under `skills/`, plus `hooks/<old>_gate.sh`.
- Only two spellings occur as names: `<prefix>-` (hyphen) and `<prefix>_` (underscore). No upper-case variant.
- Non-prefix mentions that must stay: `Agrim-Intelligence` (66), `Agrim Intelligence` (LICENSE), a hardware name and the
  retired owner slug (both inside the private-name guard test, spelled in fragments), and a regex in
  `tests/test_public_bootstrap_control.py`.
- Contexts a naive substring replace mishandles: a literal `\n` directly before the name in printed
  strings (a printed `\n` then the init skill name) — 23 lines; one dotfile named with the prefix; test function names.
  A lookbehind `(?<![A-Za-z0-9])` plus a `\n` alternative handles all of them.
- Existing `sigma-*` / `sigma_*` names (`sigma-ops`, `sigma-venv312`, ...) do not collide with any skill or hook name.
- No code references the `area:<old>-*` labels (labels are passed in as arguments), so no GitHub label change is needed.

## Spike result (mechanical rename applied to the clone, full suite run)
Skipping history (`.sdlc/{plans,research,acceptance}`, `docs/launch/evidence`) fails 5 tests, 3 of them because
shipped docs point at paths that no longer exist. Renaming those too (only CHANGELOG.md kept) is the consistent choice;
the second spike run records what remains. Genuine test fallout from the rename itself:
1. `tests/test_documented_gestures.py` SLASH regex now matches `<org>/sigma-onboarding-...` in a doc (a repo name, not a command).
2. `tests/test_legacy_compat.py` `_MARKER_LITERAL` now matches skill-name prefixes in printed output (`sigma-doctor:`).
3. Evidence/docs that name paths must resolve to the renamed paths.

## Constraints
- `git mv` must move whole directories (untracked `__pycache__` goes with them) and be idempotent.
- Hook file rename changes the path a user's installed hook config points at: no aliases (owner decision).
- Generated artifacts (docs/enforcement.md, contract/vocabulary.json, write-surface, growth-audit, golden files)
  must be regenerated, not hand-edited.
