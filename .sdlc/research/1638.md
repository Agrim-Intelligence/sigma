## Constraints & unknowns
- Unverified: end-to-end behaviour of a reviewer (any of subagent/process/command/inline) actually running
  quality_delta.py and quoting it was not run; on Sigma itself it can only ever print `no metrics configured`
  or `unmeasured`, so the "quote" path is unmeasurable here (RELIABILITY: the docs must say so).
- Unverified: whether #1637 changes the output grammar (it adds `tolerance`, a head-only re-measure, a gate
  and a waiver record). A verbatim quote is shape-agnostic, so only the `no metrics configured` literal matters;
  TD-1's cross-check makes a change there go red. What depends on #1637 and is NOT part of this goal: any
  park/merge consequence of a `worse` row, the waiver verb, `tolerance`. Review quoting stays informational.
- **Blocking Q1 (fallback scope):** the issue says fall back only on `no metrics configured`, but the script has
  two other no-numbers outcomes: whole-run `unmeasured: <reason>` (wrong cwd, no work record, uncommitted work,
  no merge-base) and a refusal (exit 2, empty stdout). Taken literally, those reviews would quote one line and run
  no tools, a regression from today's text (TD-3). Recommendation: fall back to the project's tools on
  `no metrics configured`, on any `unmeasured` line, and on empty stdout, which is a few extra words (fits the
  12-to-21-word saving; must be re-measured).
- **Blocking Q2 (who runs it, from where):** the brief is the reviewer's only input and is forbidden from naming
  the worktree path (review_context.py:544-545), while quality_delta.py must run from that worktree
  (quality_delta.py:386-397) and the documented review gestures run from the root checkout (SKILL.md:51-61,
  `--scratch "$(pwd)/.sdlc/work/<goal>"`). Options: (a) the reviewer runs
  `cd .sdlc/work/<goal> && python3 ".../quality_delta.py" <goal>` from the repo root, naming the convention in
  SKILL.md (not in the brief, so the leak check is untouched); (b) `review_context.py brief` runs it and embeds
  stdout, which grows the rendered brief that both review phases count against 5-16 tokens of headroom, and
  widens scope to review_context.py. Recommendation: (a). Note the reviewer also gets write side effects
  (scratch worktrees under the main checkout's `.sdlc/state/quality_delta/`, cleaned in a finally); for
  post-PR review the head is committed, for pre-PR review uncommitted work reads `unmeasured`.
- Non-blocking: keep or drop the Hotspots bullet (about 15 words).
- Non-blocking: lower the two ceilings to the new measurement in the same PR (ratchet hygiene) or leave them.
- Non-blocking: leak policy for TD-2; no email can appear (no author or config email is echoed), metric names come
