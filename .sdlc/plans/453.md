## Risks and decisions

- Docker auth parsing is deliberately limited to a recognized Docker `auths.*.auth` shape; malformed JSON gets only a bounded member fallback, so arbitrary JSON/base64 stays clean and values never reach output.  The test asserts location-only output.
- `_SECRET_FILE` is deliberately duplicated in the public-tree builder; the equality test is mandatory to prevent divergent publish decisions.
- The former host-only harness used retired-namespace paths and an invalid origin in its original `G18`; it is historical reproduction material only and is not an input to the final proof.  #453 commits the inventory and execution logic as `tools/goal433_attack.py`, tests it in `tests/test_goal433_attack.py`, and runs it only against the goal worktree with a corrected origin.  Thus reviewers can execute and inspect the exact 147-case proof from the PR without access to `~/.sigma-ops`.
- Unicode normalization, percent decoding, generic base64 detection, and cross-line joining are excluded because they materially expand false positives; documentation and OOS tests make that deliberate boundary reviewable.
