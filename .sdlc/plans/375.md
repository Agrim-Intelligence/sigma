# #375 plan: opt-in post guard at the loop's two gh/git chokepoints

## Goal / done_when
See `.sdlc/acceptance/375.md`. With `SIGMA_LEAK_PATTERNS` exported, a post whose title/body/comment/commit
message matches a pattern is refused before any process is spawned; unset = unchanged.

## Files

- edit `sources.py` `GitHubSource._run`: one call at top. Edit `work.py` `_run`: one call at top.
- new `tests/test_post_guard.py`; edit `docs/publish-runbook.md` (new short section + ceilings).

## Design
`check(argv)`: no env var -> return. Env set: load patterns via `leak_refs.load_patterns(None, Ctx)`
(cached by (path, mtime)); any `Refused` -> raise PostRefused (fail closed). Only write verbs are
inspected: gh issue comment|create|edit, pr create|edit|comment|close|review, release create|edit,
api (fields body/title/message/comment via -f/-F/--field/--raw-field), git commit. Text sources:
--body/-b, --title/-t, --message/-m, --comment, --body-file/-F (read file; `-` cannot be read here, so a
stdin body with the guard on is REFUSED, not passed), and `--flag=value` forms. Hit -> PostRefused
`post_guard: REFUSED [leak] <flag> pattern <N>` (line = flag + pattern line, never text, never a
`#`/SHA). PostRefused subclasses RuntimeError so existing except-paths see an ordinary failure.

## Steps (test-first)
1. tests: unset passes; each verb/flag hits; benign text passes; read verbs pass; bad patterns file
   refuses; file inside work tree refuses; stdin body-file refuses; message never echoes text.
2. implement post_guard.py; green.
3. integration tests: sources `_run` with fake run not called; work `_run` raises before subprocess;
   real-subprocess gesture (env exported, fake `gh` on PATH records calls) -> fake gh never called.
4. wire both chokepoints. 5. runbook section. 6. controls: break each guard once, see red.

## Ceilings / recovery (stated)
Per post: O(len*patterns), regex has no timeout (named in runbook). Patterns cached per process.
Not covered: raw `gh api --input`, labels/milestones, stdin bodies (refused when guard on), posts
outside the loop. Recovery: unset the variable or fix the file; refusal leaves no partial write.
Tree export is already gated by `build_public_tree.py` (leak_refs tree -> REJECTED).
