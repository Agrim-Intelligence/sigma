## Literal-token rule (every new file, this plan included)

New files ship and are scanned by the builder, `exposure_scan.py`, `leak_scan.py` and the guards. Never write literally: a private-key header (build
`"-" * 5 + "BEGIN " + kind + "PRIVATE KEY" + "-" * 5`); the OWNER-colon placeholder (build `"<" + "OWNER:"`); the SSH GitHub URL forms (build `"git" +
"@" + "github.com:"`); `basic`/`bearer`/`digest` + space + 8 or more token characters (exposure `auth`); a quoted credential assignment (`token`,
`secret`, `password` then `=`/`:` then a quoted 12+ value); a home path (`/Users/<name>/`, `/home/<name>/`, `~name/`, `-Users-name-`); token shapes
(`ghp_`, `AKIA`, `sk-`, `xox`); an e-mail outside `@example.invalid` and `@users.noreply.github.com`; `github.com/Agrim-Intelligence/<x>` with `x` other
than `sigma` (use `$NEW_NAME`); 3+ lines of 40+ base64-like chars (build bodies at run time); a word holding one of the raw roots in
`tests/test_no_private_names.py:755` (`_RAW_ROOTS`); the four stop-signal tokens of `tests/test_no_unsupervised_process_pause.py` outside
comments/docstrings; a network module (`socket`, `urllib.request`, `http`, `ssl`); a `#` + 4-digit number; in a shipped `.md` (sweep
`tests/test_readme_first_run.py:477-523`) a three-part version above the plugin's own, or below it after a release phrase (`since`, `in`, `from`,
`before`, ...), or a two-part one after `in`/`since`, unless a program name (`python`, `macos`, `git`, `gh`, `node`) directly precedes it; a fenced line
that starts and ends with `|` and has no `| --- |` row after it (`tests/test_docs.py:2088`); any token of the `banned` tuple at
`tests/test_self_contained.py:55` (read it there, never copy it). A finding in a file this PR creates is FIXED there, never allowlisted.

### `tools/build_public_tree.py`

```
python3 tools/build_public_tree.py COMMIT --out DIR [--source DIR] [--patterns FILE] [--sdlc exclude|include] [--exclude PREFIX ...]
    [--review-level clean|landed|pr-merged|owner-merged] [--repo OWNER/NAME] [--remote NAME] [--base BRANCH] [--report-dir DIR] [--scan-timeout S]
```
Defaults: `--source` = git top level of the cwd; `--patterns` else `$SIGMA_LEAK_PATTERNS` (one is required; no default path); `--sdlc exclude`;
`--review-level pr-merged`; `--remote origin`; `--base main`; `--report-dir ~/.sigma-ops/public-tree`; `--scan-timeout 900`. Exit 0 = VERIFIED (export
at OUT); 1 = REJECTED (export at `OUT.rejected`, report written); 2 = refusal (no export, no report, partial removed) or NOT-VERIFIED (a scan exited
outside {0,1} or timed out: export at `OUT.rejected`, report written, stderr `REFUSED [scan-failed] <scan> exited <rc>; report: <path>`).
Stdout on exit 0/1, in order: `verdict: <V>`, `commit: <40 hex>`, `tree: <id>`, `export-commit: <id>`, `out: <path>`, `report: <json path>`, `scans:
builder=<n> leak_refs=<exit>/<hits> exposure=<exit>/<findings>+<stale> leak_scan=<exit|absent>`.

Module names tests use: `main`, `_real_run`, `_platform_is_windows`, `Refused`, `SCHEMA = "sigma.public-tree-report/v1"`, `DISPOSITIONS_SCHEMA =
"sigma.public-tree-dispositions/v1"`, `DISPOSITIONS_PATH = "docs/launch/public-tree-dispositions.json"`, `EXPOSURE_ALLOWLIST_PATH =
"docs/launch/exposure-allowlist.json"`, `SDLC_DEFAULT = "exclude"`, `AUTHOR_NAME = "sigma-public-snapshot"`, `AUTHOR_EMAIL =
"noreply@users.noreply.github.com"`, `MAX_BLOB_BYTES = 2 * 1024 * 1024`, `KEY_HEADER`, `OWNER_PLACEHOLDER`, `SECRET_FILE` (compiled;
`SECRET_FILE.pattern == leak_scan._SECRET_FILE.pattern`), `blob_id(data) -> str`, `tree_id(entries) -> str` (entries: `(path: str, mode: str,
blob_hex: str)`, modes `"100644"`/`"100755"`; git order: names as UTF-8 bytes, a subtree compared as `name + "/"`, subtree mode `40000`),
`materialise(src_root, entries, dest, excluded=()) -> dict` (`entries` as for `tree_id`; `excluded` = the excluded paths, `str`, feeding

## Risks against the five properties

- RELIABILITY: a green build over half-blind scans. Mitigated: unreadable kinds refused before any scanner can count-and-skip them; the builder's own
  header rule; mandatory patterns; four-way tree equality; tool provenance. Residual, printed in every report: header-less key bodies (#433), exposure's
  rule de-duplication, names missing from the patterns file. The full suite on an export is measured in T6.6, not before.
- SCALABILITY (research prototype, 798 files / 17.4 MB): plan 0.02 s, materialise 0.17 s, re-derive 0.05 s, `leak_refs tree` 0.37 s, exposure 11.2-19.3 s,
  `leak_scan` 5.5 s: 18-26 s per build, scanner-bound. 10x (8,000 files, 174 MB): exposure about 2 min (one `git rev-parse` per path, about 14 ms) and
  its `cat-file --batch` holds all blob bytes (174 MB); the builder's passes about 2 s, memory bounded by the 2 MiB blob cap. 100x: exposure about 20
  min and 1.7 GB held: the ceiling is `exposure_scan.py` (extrapolated, not measured; follow-up). `--scan-timeout 900` turns a hang into NOT-VERIFIED.
  Checker: about 10 ms per repository (1,152 in 12 s; 10x about 2 min), capped by `--max-depth 5`/`--max-repos 2000`, truncation blocking.
- RESILIENCY: build in `OUT.partial-<pid>`, rename at the end; refusals remove the partial; a crash leaves only the partial (lever: delete, re-run; the
  export is a pure function of the commit, so re-running is idempotent); OUT never overwritten; reports create-once via `os.link`; a missing report
  reads as not verified; REST failures refuse, never pass; no retries (owner-run, one-shot).
- SAFETY: OUT, reports, patterns and `--json` outside every work tree (a loop's `git add -A` never finds them); patterns and matched values never printed,
  exposure previews discarded with their temp JSON; reports 0600; network only through opt-in `gh api` GETs; no gh write (write-surface tests, GET-only
  fakes); the checker writes nothing but `--json`; Windows and non-sha1 refused; neutral fixed identity, no private sha in the export. The ~980 stale
  scratch repositories holding the old origin are listed, never changed.
- LIVENESS: no daemon. Health = exit code + report + `generated_at`; `landed` records the local remote-tracking ref's distance and says the builder
  does not fetch, so a stale export is visible. The sequence stops writers with `watch.stop` (never a stop signal) and the checker confirms by process
  and heartbeat age (600 s threshold).
