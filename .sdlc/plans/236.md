  sdlc_init (scaffold/owner/demo/board_offer/git_refusal), preflight (#229), verify_detect (#228),
  `setup.py labels` (#230), `board_setup.py create` (#235). `sdlc_init.py` stays as the low-level
  scaffolder (its `--github` gesture keeps working; it is the control's "old gesture").
- **D2 Questions are flags.** mode (`--mode local-goals|github`, `--repo O/N`), work (`--local-only` /
  `--work on`), verify (`--verify N:ID` | `--verify-command-file F` | `--no-verify`), board
  (`--board yes|no`), ledger (`--ledger yes|no`). An unanswered question prints `[ask]` with the exact
  flag to re-run with: Claude Code asks the user, Codex/Cursor relay it.
- **D3 `--yes` defaults only the safe answers**: mode = detected (github iff `origin` parses as a GitHub
  owner/repo), ledger = no. It never answers board, verify, or a work.enabled flip — those change external
  state or need the user's own knowledge (#235 "never unasked"; #228 "never guess"; #229 "nothing flips it
  silently").

  decisions: idempotent, zero label writes the second time.
- **D5 Exit codes**: 0 = every attempted step ok (open `[ask]`s allowed); 1 = a step FAILED or preflight has a
  blocking `[FAIL]`, always with a `Resume:` line naming the exact command; 2 = refused before writing
  (not a git repo, coexistence, github mode with no repo).
- **D6 Assignee** `@me` is applied only where unset/null (setup.py's `_apply_default` rule) — never asked.
- **D7 Example goal** ships `status: proposed` (loop never picks it); `--demo` still queues a pending demo.
- **D8 Wizard adoption gate** in `setup_wizard.wizard_status()` (Python, host-agnostic): adopted =
  `.sdlc/config.json` exists and `state/owner.json` does not name another plugin. Unadopted → silent. #186.
- **D9 Nags**: the work.enabled warning names `/agrim-init`; it is silent when `work._enabled_why` records a
  deliberate choice (written by `preflight.py local-only` and by the flow).
- **D11 (found in P5) `project.enabled` follows the board answer in github mode.** The template ships it
  on, and the loop FINDS OR CREATES a board on its first github pick while it is on -- so "no board
  without a yes" held for init and broke at the first `loop.py next` (the E2E's fake gh showed preflight
  demanding the `project` scope). Unanswered/`--board no` -> off with `_enabled_why`; `--board yes` -> on.
  A pinned `project.number` is never touched.
- **D12 (found in P5) `/agrim-init --github` stays accepted** by the flow as `--mode github
  --github-templates`: the README and old muscle memory use it, and `test_readme_first_run` checks every
  README `/agrim-init --flag` is accepted.

  `detect`), and refuses a missing `.sdlc/` instead of a traceback. `setup.py init …` execs `init_flow.py`.
