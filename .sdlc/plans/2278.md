## Decisions (research's open points; all inside the brief's own fallbacks)
1. **Section reader: write the smallest one in reuse.py.** `acceptance._section` (acceptance.py:61-93) is a checklist
   parser: it returns only bullet texts and raises `ValueError` on the first non-bullet line (:82-86), so the first
   `**Source:**` line or table row would raise. The brief's step 3 fallback applies: `_section_lines(text, heading)`
   keeps `_section`'s fence rule verbatim (acceptance.py:66-70: a fence opens on ```` ``` ```` or `~~~` and closes only on
   the same character) and returns the raw unfenced lines. #2279 reuses it for `## Test design`. The PR body says why.
2. **`parse_reuse` keys: the brief's five plus five, additive only.** `searched_at` (raw text after `**Searched at:**`,
   or None; #2281 reads it), `bad_queries` (1-based positions, among all `- ` lines of the section, of lines that are
   not a well-formed query), `header` (the first `|` line verbatim, or None), `separator` (bool: the second `|` line is a
   separator row), and per row `cells` (the cell count). `queries` keeps the brief's `[(pattern, [paths])]` and holds
   only well-formed lines, so a later caller never sees a malformed one. Rows always carry all five named keys (missing
   cells are `""`).
3. **Fence-aware, both ways.** A `## Reuse` heading inside a fence is no section, and a `**Source:**` /
   `**Searched at:**` line inside a fence is no marker. Both lean to legacy, the direction that never refuses.
4. **Row rules split out.** `table_errors(parsed, root)`: header, separator and every row rule, and `[]` when there is
   no table. `reuse_errors(parsed, root)` = Searched-at shape + none line + query rules + "table has rows" +
   `table_errors`. #2282 calls `table_errors` on a plan's optional table (it has no queries or Searched-at line).
5. **Git env scrub: reuse `bounded_run.LOCATION_VARS`** (bounded_run.py:106-108, public, same skill), loaded at call
   time through `_load`, never at import. `git -C` does not override an exported `GIT_DIR`. Timeout 10 s, the
   reviewer brief's own git budget (`_git_out`, review_context.py:380-392). No fifth copy of the set.
6. **Evidence path safety: yes.** The query path rule (`_path_error`) also applies to the file part of `reuse`,
   `extend` and `dependency` evidence: `pathlib.Path(root) / "/etc/hosts"` discards `root`, so an absolute path or a
   `..` path would otherwise "exist". A symlink inside the project that points outside is not resolved: the probe is
   `is_file()` only, a one-bit answer; stated as a ceiling in the docstring.
   `dependency` takes `file:line` only, as the brief's table says (a range is refused there; `reuse`/`extend` take both).
7. **One test per clause** beyond the brief's list: tests T8-T12, T14, T17-T18, T21-T23, T26, T29-T30, T32-T33, T35,
   T37, T40-T44, T47, T51, T54-T55 below. Each is named in the control table.

Also settled: section-level errors start `Searched at:`, `none:`, `queries:` or `table:`; row errors start with the row
id, or `row <k>` when the id itself is malformed; query errors start `query <n>`. Error text never echoes a dossier value
except through `repr` (control characters arrive escaped). The success line is the brief's exact text (FR-4's "names
the dossier" is met by naming the goal; #2279 rewrites the line). Paths split on a single space (`split(" ")`), so a
double space yields an empty path the empty rule refuses. Control characters: `[\x00-\x1f\x7f]`.

`_check` order (brief step 6): `text = dossier_text(...)`; empty -> `([], [LEGACY_NO_DOSSIER], None)`; `len(text) >
MAX_CHARS` -> `(["research dossier is over 1048576 characters; nothing checked"], [], None)`; `parse_reuse(text)` not
present -> `([], [LEGACY_NO_SECTION], None)`; `not is_new_format(text)` -> `([], [LEGACY_OLD_SECTION], None)`; then
`root = _load("review_tests")._root(sdlc_dir, goal)` (ONE call; it loads `work`), `errors = reuse_errors(parsed, root)`,
and `if commit_exists(root, parsed["searched_at"]) is False:` append `Searched at: commit <first 7> is not on this
machine` to errors with `at_research`, else to warnings. The rev-parse argv is exactly
`["git", "-C", str(root), "rev-parse", "--verify", "--quiet", "--end-of-options", commit + "^{commit}"]`.

`parse_reuse(text)` walks `_section_lines(text, "Reuse")`: a line starting `**Source:**` / `**Searched at:**` sets that
key to the stripped rest; a line starting `none:` sets `none`; every line starting `- ` is a query line (counted; a
`_QUERY.fullmatch` gives `(pattern, paths.split(" "))`, else its position goes to `bad_queries`); every line starting
`|` is a table line. Table: first line -> `header` (verbatim), `separator = len(table) > 1 and
bool(_SEPARATOR.fullmatch(table[1].strip()))`, rows = `table[1 + separator:]`, cells =
`[c.strip() for c in _CELL.split(line)[1:-1]]` (cells kept raw: `\|` is not unescaped). Other lines are ignored.

`reuse_errors` messages, in this order (tests assert these strings exactly):
- `Searched at: missing; write **Searched at:** <the full commit id Research ran at>`
- `Searched at: not a full commit id (40 or 64 lowercase hexadecimal characters)`
- with `none` set (then nothing below runs except `table_errors`, which finds no table or reports it):
  `none: needs a reason of three words or more`; `none: replaces the queries and the table; keep one or the other`
  (when any of `queries`, `bad_queries`, `header` is present).
- `queries: <n> recorded; 1 to 25 allowed` (n = good + bad query lines)
- per query position n: `query <n>: not of the form - pattern: `<regex>` paths: `<path> [<path> ...]``;
  `query <n>: pattern is <k> characters; 1 to 200 allowed`; `query <n>: pattern contains a control character`;
  `query <n>: path <repr> <_path_error text>`
- `table: no rows; a goal that adds no capability writes none: <reason> instead`
- `table_errors`: `table: the header row must be exactly <HEADER>`; `table: the header row must be followed by a separator
  row`; per row (who = id if `_ID.fullmatch(id)` else `row <k>`): `<who>: id <repr> is not RU-<number>`;
  `<id>: id appears more than once`; `<who>: <n> cells; a row has 5` (then the row's other rules are skipped);
  `<who>: capability is empty`; `<who>: decision <repr> is not one of reuse extend stdlib dependency dependency-new new`;
  `<who>: decision <repr> needs evidence: <DECISIONS[d][0]>`; `<who>: decision <repr> needs a reason of <DECISIONS[d][1]>`
  (so `RU-3: decision 'new' needs a reason of three words or more`, the brief's example, verbatim).

Evidence rules (`ok` per decision): `reuse`/`extend`/`dependency`: `m = _FILE_LINE.fullmatch(ev)` and (decision is not
`dependency` or `m.group(3) is None`) and `not _path_error(m.group(1))` and `(pathlib.Path(root) / m.group(1)).is_file()`;
`stdlib`: `_MODULE.fullmatch(ev)`; `dependency-new`: `_PINNED.fullmatch(ev)`; `new`: `ev in ("—", "-")`. Reasons:
`dependency-new`: `reason.startswith("verified:") and len(reason[len("verified:"):].split()) >= 3`; `new`:
`len(reason.split()) >= 3`; others: anything.

`main(argv)`: `argv in (["-h"], ["--help"])` -> `print(__doc__)`, 0. `at = argv[-1:] == ["--at-research"]`; `args =
argv[:-1] if at else argv`; `len(args) != 3 or args[0] != "check-research"` -> `print(USAGE, file=sys.stderr)`, 2. Else
`errors, warnings, parsed = _check(args[1], args[2], at)`; every warning then every error to stderr as `reuse.py: <text>`;
errors -> 2; `parsed is not None` -> stdout `reuse.py: ## Reuse for goal <goal> is well formed (<len(rows)> rows,
<len(queries)> queries)`; return 0 (a legacy goal prints nothing on stdout).

## Scale, safety, liveness
- Per call: one dossier read (whole file: the 1 MiB cap bounds parsing, not the read, because `_phase_doc` and `git
  show` read it all; stated in the docstring), up to 4 git calls from `_branch_doc` only when no file is on disk (10 s
  each), one `rev-parse` (10 s), one `is_file()` per evidence row. Linear in dossier size; a 1 MiB dossier caps rows at
  about 30,000 stats. Nothing scans across goals, so 10x or 100x goals cost the same per check. `_root` and
  `_branch_doc` load `work` at call time (about 106 ms, measured once by research, not benchmarked); nothing loads at
  import (live-copy cap, tests/conftest.py:107-115).

- Trust boundary: dossier text reaches git only as a value that fullmatches `SEARCHED_AT`, checked inside
  `commit_exists` itself (every later caller passes through it), as an argv list after `--end-of-options`, with the
  GIT_* location variables removed. Recorded patterns and paths reach no process in this slice (#2281 will run them;
  the path rules here are what makes that safe). Echoed dossier text goes through `repr`.
