## Test notes
Deterministic nodes at the seam (in-process): rotates at the cap and keeps exactly N generations; the line that triggered the rotation is in the fresh file; nothing below the cap rotates; a held live lock skips rotation but the line is still written; a stale lock is taken over; a rival that rotated while we waited makes the re-check skip (no double shift); a crash (os.replace raising mid-shift) leaves the current content intact and the next write succeeds; cap derived from free disk and floored; non-OSError-safe. Integration: `_log` and the supervisor append path rotate; supervisor copy of an oversized session is bounded; secrets in a `_log` message are scrubbed in the live file after rotation. Real-subprocess concurrency test is a labelled SMOKE test only (generations large enough that no line may be evicted). `test_b6_460.py`: disposition covers exactly the five patterns; capped entries name a callable that exists; launchd entry decision claims unbounded and no Sigma source opens that name; gesture parsed out of growth-audit.md run in a scratch repo shows the five patterns out of `unresolved_patterns` and `pruner_or_cap` carried.

## Controls (each broken once, seen red, restored)

3. Rotate by deleting the current file instead of `os.replace` -> data-preserved node red.
4. Revert `_log` to a plain append -> the slack integration node red.
5. Revert the supervisor `_append`/copy -> supervisor nodes red.
6. Delete `460.json` -> audit node red, run with the exact gesture from growth-audit.md.

## Scale / recovery
Per write: one stat. 100x lines => rotation 100x more often, disk still <= 4 x cap per log; the cost is a shorter retention window (about 30k lines of ~100 B kept at 1 MiB). Crash mid-rotate: current file untouched or already moved, the writer's `open("a")` recreates it; the oldest generation may be evicted early on a re-run, never the live line. Stale `.rotating` after a crash: taken over after 60 s. Restore-from-backup: old files are just logs. No process pausing, no human.
