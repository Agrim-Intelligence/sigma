## 1. What changes, in one paragraph

`protection()` stops swallowing both reads. Each source ends as one of three things: it **requires** something, it **answered nothing**, or it is **unreadable** (with a reason built from `gh_api.classify` plus fixed words, never from the failure text). If either source found a requirement the result is `(True, "<base> enforces ...")` as today. Else if either source was unreadable, `protection()` raises `ProtectionUndetermined` whose message begins `protection could not be determined for <base>` and `merge()` returns `PR #N <verdict>, but <that message><ratchet clause> — merging it is yours to make (auto_merge: "<policy>")` for **both** `protected` and `always`, with no PUT and no `--auto`. Only when both answered nothing does it say `not protected — nothing is enforced on merge` (classic 404) or `protected but requires no checks or reviews` (a readable empty classic object). `_ruleset_requirements` now raises `ValueError` for a reply that is not a JSON list. AC-1, AC-2 and AC-4 are untouched in behaviour and re-proved; the tests that pinned the opposite of AC-3 are flipped.

## 2. The design

### 2.1 Classification of each reply, per source (code: `_read_classic`, `_read_rules`, Appendix B)

"Message" below is the failure text `_pr_api_run` leaves in `.hint` (after the argv prefix); `gh_api.classify` gives `(status, kind)` from it (`gh_api.py:207-235`).

| Reply | Classic `branches/<b>/protection` | Rules `rules/branches/<b>?per_page=100` |
| --- | --- | --- |
| 200, JSON object | **answered**: requirement(s) if any `contexts`/`checks`/review count >= 1, else answered-nothing ("configured, requires nothing") | unreadable ("not a JSON list") |
| 200, JSON list | unreadable ("not a JSON object") | **answered**: requirement(s) if any counted, else answered-nothing ("listed, nothing counted"); a malformed item inside contributes nothing |
| 200, empty body | unreadable ("the reply was empty") | unreadable ("the reply was empty") |
| 200, not JSON | unreadable ("not JSON") | unreadable ("not JSON") |
| 200, `null` / number / string | unreadable ("not a JSON object") | unreadable ("not a JSON list") |
| 200, object with `required_status_checks` or `required_pull_request_reviews` of the wrong type | unreadable ("not a protection object") | n/a |
| 404, message exactly `Branch not protected` (real: `gh: Branch not protected (HTTP 404) -- fix: ...`; fixture: `HTTP 404: Branch not protected`) | **answered-nothing** ("none configured") | unreadable (`read failed (not_found, HTTP 404)`) |
| 404, any other message (`Branch not found`, `Not Found`, bare `HTTP 404`, `... on this fork`) | unreadable (`read failed (not_found, HTTP 404)`) | unreadable |
| 403, with or without the answer text | unreadable (`permission`, or `rate_limit` by text) | unreadable |
| 429, 5xx | unreadable (`rate_limit`, `server`) | unreadable |
| transport error, timeout, proxy block, any other exception (including `FileNotFoundError`) | unreadable (`transport`, `proxy`, `other`) | unreadable |
