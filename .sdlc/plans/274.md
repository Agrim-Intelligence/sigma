   documented CLI without `--max-usd` and preserve its refusal; then add the
   ceiling and assert a schema-valid two-row result.  Include a red control that
   moves a hidden bundle under a task tree and proves the harness refuses it.
2. Add `evals/bench/bench.py`. Refuse every live arm until a separately
   reviewed enforceable boundary exists;

   manifest validation, fresh task copies, explicit command argv execution, and
   a versioned result schema.  Never use a shell string.
3. Enforce launch safety before work begins: require a positive `--max-usd`,

   hidden root or bundle path into the arm environment or API.  Refuse before an
   arm starts unless the operator supplies an absolute executable external

   refused even when a launcher is supplied.

   fake command in tests only; no live model run or spend is authorized.
   Pass each arm only the remaining ceiling and refuse before result-row output
   if it reports a cost above that allowance; prove this with a two-task control.
5. Document the exact smoke gesture in `evals/README.md`, run the focused
   controls and full suite, obtain independent review, then commit/PR/CI/merge
