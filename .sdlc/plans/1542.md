### Semantics change (coordinator decision; the orchestrator records it on epic #1539)
`zones.py check --plan` NEVER prints `over`. A seam edit to a legacy file must appear in `## Files`,
and the acceptance record is frozen, so the old plan-mode `over` (any named legacy file without
intent) would reject every legitimate sprout or wrap with no way to fix it. Plan mode now lists each
named legacy file with its intent and prints `within` when the record is readable, else the AC-4
`intent: unknown` line and `unknown`. Size is measured only by `check --diff` at review (changed lines
vs `design.restructure_lines`); diff-mode `over` is untouched. AC-1 stays satisfiable: it is
conditional on the printed verdict, and its clause is dormant at plan time.
