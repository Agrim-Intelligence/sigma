## Documented gesture and receipt

`python3 tools/parity/resources.py --reserve-fraction 0.25 --record-bytes 256 --output-dir .`

Both numeric inputs are required: the fraction is an operator policy input, and record-bytes is the caller's observed serialized record size, labelled caller-supplied in the receipt. No OS/test/source override flags exist. The command writes no file and invokes no executable/network service. Success prints one JSON receipt; a typed refusal prints one JSON object on stderr and exits 2 without a successful receipt. Argparse input failures also exit 2.

Receipt schema parity-resource-preflight/v1 records platform/Python/time, every memory source and its arithmetic, reserve numerator/denominator, input record size, CPU count, output-volume free bytes, and derived limits. It explicitly states that values are snapshot-derived capacities, not allocations/reservations or measured scan throughput.

## Task 1 — test and implement native source collection

1. Add tests first and observe missing-module failure before source code exists.
2. Linux: parse MemAvailable and MemTotal in kB; parse /proc/self/cgroup and mountinfo with exact controller/root/path mapping. Refuse active v1 memory accounting. For v2 walk the process's group to the full mounted root and read every finite memory.max minus memory.current. Preserve unlimited max rows. Reject ambiguous/non-root mounts, traversal, missing or malformed data and exhausted ancestors. An absent controller is explicit, not an invented finite cap.
3. macOS: checked ctypes binding to libSystem host_statistics64, HOST_VM_INFO64, vm_kernel_page_size and sysctlbyname hw.memsize. Count free+inactive only and verify against physical total. Release host port. Use TASK_VM_INFO revision-0 virtual_size for a finite RLIMIT_AS, with 4-byte struct packing as in the SDK.
4. Windows: checked GlobalMemoryStatusEx, validate available physical memory against total, and call GetDiskFreeSpaceExW for the output volume. Unsupported API/platform refuses. No subprocess fallback.
5. Apply a finite POSIX RLIMIT_AS only after subtracting measured current virtual space; negative/zero/exhausted/missing evidence refuses. Unlimited is explicit.
6. Positive integer/finite source validation rejects booleans, malformed values, inconsistent totals and zero usable capacity. Tests patch native/proc seams, never add a stronger test-only CLI flag.

## Task 2 — test and implement the calculator and CLI

1. Validate fraction as finite and strictly between zero and one; validate record size as a positive integer within sys.maxsize.
2. Available = minimum of applicable physical/cgroup/address-space remaining sources. Compute reserve using the exact binary float numerator/denominator and integer division, recording both.
3. Divide usable capacity into decode budget and output-buffer budget, recording the split. The decode expansion bound is one encoded byte plus sizeof(uint32) per encoded byte, plus the interpreter-measured bytes/string object overhead. This bounds raw+decoded text only, not AST allocations.
4. Derive worker slots as min(observed CPU count, decode budget divided by one serialized-record decode cost). Derive per-worker raw-blob ceiling from its decode share. Derive output record count and bytes from output-buffer budget and the supplied encoded record size. Reject any zero result; all simultaneous budget partitions sum to at most usable.
5. Measure an existing output directory's free space via fstatvfs on POSIX or GetDiskFreeSpaceExW on Windows. Refuse if it cannot hold the derived output byte ceiling. Never create the output directory/file.
6. Test the literal documented CLI argv in-process while patching only measurement seams. Tests deny process/network calls and assert no files are created. Test success, each refusal and intact restoration.
