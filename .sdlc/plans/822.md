## Design (short)
- Model drafts `answers.json`: `{"outcomes":[{"name","section","answers":{...bank ids, open_*},"cites":{"<id>":"<verbatim quote>"}}]}`. `intake.py` is the deterministic half; it never reads the PRD with an LLM.
- `plan --prd P --answers A [--sdlc-dir D]`: validate, hash, print mapping `PRD section -> Dossier title -> answer ids`, write `D/intake/<sha12>.json` (normalised per-outcome dossier answers). Exit 2 `REFUSED [code]` on stderr, empty stdout.
- `file --plan D/intake/<sha12>.json [--dry-run]`: files each Dossier via `dossier.file(..., prd_source={...})` (`source` is already the BACKLOG source arg of `file`; the PRD stamp is the new `prd_source`), then ONE umbrella via `create_dependency(goal_label=False)` labelled `epic` (GitHub mode: label existence checked before the first Dossier is filed, `REFUSED [umbrella-label-missing]` or minted by create_dependency's idempotent label-create, whichever the research-confirmed behaviour is, pinned by a test), body lists every `#N`. Dry-run first (documented order).
- Input: PRD as a file path only. DEFERRED (stated in SKILL.md): stdin text and issue number (a stdin PRD has no stable path; an issue PRD needs a read through sources, a separate slice).
- Size cap: PRD <= 262144 bytes (declared constant `MAX_PRD_BYTES`, refuses `prd-too-large`; a PRD past it is split by the human). Cost per PRD: O(len(PRD) * cites) substring checks, one `file` call per outcome plus one umbrella; outcomes capped at 12 (`too-many-outcomes`, above that the umbrella is the wrong shape). 10x/100x: linear, no lock, no table growth.
- No network in tests: local-goals config or injected `run`; nothing spawns a process; no secrets touched.
- Recovery: `file` writes `D/intake/<planhash12>.filed.json` (keyed by a hash of the PLAN file, not the PRD; see Revision 1) after EACH Dossier (outcome name -> #N). Re-run skips named outcomes already filed and files only the rest, then the umbrella (skipped if recorded). A crash between create and record can duplicate one Dossier: documented lever = `intake.py file --plan P --status` lists recorded numbers; the human closes the duplicate. Stated, not claimed away.
