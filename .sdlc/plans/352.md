- **D4 Split rule.** `ast`, not a regex (`render.py` has a docstring line starting `class `). Boundary = first decorator line else the def/class line,
  hoisted over directly contiguous comment lines (`lstrip().startswith("#")`: an indented method comment travels with its method). Recursive descent:
  a class over the cap also contributes its direct `FunctionDef`/`AsyncFunctionDef`/ `ClassDef` children, and a nested class over the cap descends
  again (sources.py is ONE 4,298-line class; the literal top-level rule gives a 4,361-line piece: a PR-body deviation). Greedy: cut at the latest
  boundary b with `pos < b <= pos+cap`; exactly 3,000 is one unit. Fallback (def over cap, no-def file such as a `.sh`, `ast.parse` failure): last
  blank-line boundary in the window, else a hard cut, stderr note. Pieces tile 1..n.
- **D5 Packing.** Only files <= 3,000 lines pack, per-directory next-fit in bytewise path order, units never span directories, pieces of a split file
  stay alone (else the issue's own three-small-files test fails). Sort units by (first path, first start), THEN number `A01..`/`B01..` (width max(2,
  digits)).
- **D6 Draw whole files, then split+pack only the drawn** (packed units can be 5% of the population: 15-25% would be unreachable on a small repo).
  `rng = random.Random(seed)`; keys `rng.random()` over bytewise-sorted paths; walk in `sorted(by (key, path))` order; add a file if `cum + n <=
  pop*22//100`; stop at the FIRST `cum >= ceil(pop*20/100)`; stderr warning below 15%; exit 2 on empty population or empty draw. `draw` returns files
  IN WALK ORDER (`build` sorts them) so a test sees where the walk stopped. KNOWN BIAS, stated in the doc and the docstring: the ceiling skips a file
  that would overshoot, so large files are under-drawn: doctor.py is drawn in 15.3% of 3,000 seeds at 22%, 18.6% at 25%, 21.9% with no ceiling
  (re-measured, as plan-review did). Kept: 22% keeps results inside 15-25% (20.00-21.99% over those seeds).

  newline, `start`/`end` 1-based inclusive, `--sha` required. `--json PATH` is ONE plain `Path(args.json).write_text(...)` in `main` after

- **D10 `apply`** (simplified; every git fact here probed on git 2.39.5 in plan-fix). Refuse (exit 2, naming the cause) BEFORE any change, in order:
  `seed_dir` not a directory or no `*.patch`; clone not its own `rev-parse --show-toplevel` (`os.path.samefile`, not `==`); `seed_dir` equal to or
