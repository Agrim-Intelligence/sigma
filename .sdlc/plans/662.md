- **F-1 read ceiling (deviates from design wording "the existing helper").** No helper exists in doctor.py
  (only the provisional constant `MAX_STORE_READ`, ~1644). Do NOT call `quality_delta.probe_memory` (spawns
  `vm_stat`). New `_arch_read_ceiling()` = `os.sysconf("SC_PHYS_PAGES") * os.sysconf("SC_PAGE_SIZE") // 4096`,
  clamped to [64 KiB, 8 MiB]. HONEST STATEMENT: the 4096 divisor and the 64 KiB / 8 MiB clamp are CHOSEN
  constants that bound a memory-derived value; the value is host physical RAM, not cgroup/container limit,
  and therefore differs across the fleet (nondeterministic across machines). Recorded ceilings: 1 GB -> 256 KiB,
  2 GB -> 512 KiB, 8 GB -> 2 MiB (16 GB+ capped at 8 MiB); the measured 10,000-rule north-star size (step 17)
  is recorded against 1/2/8 GB. If either sysconf value is missing, raises (ValueError/OSError/AttributeError)
  or is <=0, the ceiling is `None` and the read is refused loudly as `unreadable: cannot derive a read limit`.
  Reads: `os.stat` S_ISREG required (FIFO/device/dir refused, never opened blocking); then
  `open(..., "rb").read(ceiling+1)` and refuse if `len > ceiling` (no stat-then-read_text, so a file that grows
  between stat and read is still bounded). When the north-star is PRESENT but unreadable (over ceiling, sysconf
  unavailable, not regular, decode/OS error) both `check` and `rules` print an explicit advisory line
  `architecture rules could not be read: <reason>`; `rules` exits 1 in that case (a rule file we cannot read must
  not look like "no rules").

## Grammar (D-2, D-4, implemented once)
- Section: from first heading `^#{1,6}\s+Architecture\b` to next heading of same or higher level; none => no rules (silent).
- Rule: a line `^\s{0,3}(\d+)[.)]\s+(.*)`; continuation = following lines until next numbered line, next heading, or a blank line followed by a non-indented non-blank line. Rule text containing `<...>` placeholder at its start (`1. <e.g. ...>`) is skipped.
- Suffix: case-insensitive `Enforced by:` anywhere in the rule's lines; specs comma-separated: `ci:<path>` (part before `::` checked), `decide:<id>` (single token, no whitespace/colon), bare `review` (keyword case-insensitive; path/id case-sensitive). Anything else, `ci:` empty, `decide:` with a space = malformed => broken with reason.
- Classes: `enforced` (>=1 valid ci/decide, none broken), `broken` (any spec bad; a good spec does not rescue), `review-only` (all specs `review`), `untagged` (no suffix). Review plus a good ci/decide = enforced.
- `ci:` valid iff: not absolute, no `~`/`\`/NUL, resolved path stays inside repo root (`resolve()` then `relative_to`, symlinks followed so a link out is refused), `is_file()` and (case check) the resolved path's final components equal the spelled ones when the FS is case-insensitive (compare `os.path.realpath` spelling case; on mismatch report `case differs: found <actual>`; if this cannot be done portably, document the limit instead and say so in the footer); directory => "is a directory, name the file"; missing => "file not found". Containment is checked BEFORE any `stat` of the target. ALL ci validation sits in one try/except
  (OSError, ValueError for NUL, RuntimeError for symlink loops on 3.12) converting to a typed reason, never raising.
- `decide:` valid iff registry loaded and id present with active status; reasons: registry missing, registry unreadable (malformed JSON / not a dict / over ceiling), id absent, id superseded (names status).
