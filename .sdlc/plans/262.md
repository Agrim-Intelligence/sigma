# Plan — #262 phase instruction budget

## Acceptance criteria

1. Ship `evals/phase_context_budget.py`, a stdlib-only report/gate that resolves the documented
   instruction files for every listed phase, renders review packs against `examples/hello-sdlc/`,
   and reports words plus the shared approximate-token estimate.
2. Commit the measurements, ISO date, and exact source commit in `evals/phase_context_budget.json`.
3. Fail if a measured phase exceeds its recorded ceiling or if a ceiling is more than 5% above the
   current measurement.  This permits only downwards ratchets.
4. Prove the exact documented command fails after a planted 500-word addition to
   `skills/sigma-loop/references/running.md`.

## Steps

1. Add failing tests for phase/file resolution, review-brief fixture inclusion, both ratchet
   directions, and a real subprocess control that writes then restores a 500-word appendix.
2. Add the measurement module.  Keep the phase-to-file mapping explicit and use
   `skill_structure.estimate_tokens`; dynamically load `review_context.py` to render the three
   review briefs against the fixture.
3. Generate JSON from the clean tree, then run the documented gate and focused suite.
4. Ask an author-blind reviewer to inspect the diff and evidence.  Address findings, then run the
   full repository suite before committing and handing off for PR creation.

## Non-goals

- No prompt text or phase workflow changes.
- No live GitHub or model calls.
- No automatic ceiling increases.
