## Scalability / Resiliency / Safety
- Scale: one small JSON read per `route_of`, plus a one-goal log scan only without a record route. One timeline write per explicit classify; none on the default.
- Resiliency: local writes first, then the note. A failed note prints FAILED and exits 1. A re-run is idempotent (newest row wins).
- Safety: no new background work, key or gh call site. The fold is never honoured under an org lock. An explicit `action_log: false` is respected.
