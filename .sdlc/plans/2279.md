## Decisions
- **Q1 (no record, and the config cannot be read)**: `_enforced(sdlc_dir)`: `ConfigMissing` (no `config.json`, every
  test project and every repo never `/sigma-init`'d) reads as OFF, phase_gate's rule (`phase_gate.py:253-256`), so the
  goal gets the warning. Any other failure (`ConfigInvalid`, a non-object `verify` raising `AttributeError`, an unreadable
  file) reads as ON and refuses with the brief's text: state.py:36-42 forbids a corrupt config silently becoming the
  defaults, so this check fails closed. It stays consistent with "goals in flight warn, never refuse": a legacy dossier
  returns before any of this runs, and this branch fires only when the acceptance record is ALSO missing. Ceiling, stated
  in the docstring: `load_config` itself calls a top-level non-object `config.json` "missing" (state.py:75-79), so that
  one corrupt shape reads as off.
- **Q2 (`none:`)**: a Failure path cell whose lowercased text starts `none:` is judged ONLY by the three-words rule
  (`len(cell[5:].split()) >= 3`), the `reuse_errors` none-line precedent (`reuse.py:236-238`); so `none: two words` is
  refused. "A case" is `_is_case(cell)`: lowercased cell not in `("", "n/a", "—", "-")` and not starting `none:`. The
  sensitive rule uses `_is_case`, so a Hostile input of `none: …` is NOT a case. Case-insensitive on purpose:
  `None: two words` and `N/A` cannot slip through as "cases".
- **Q3 (`parse_risk`)**: the header region is the unfenced lines before the first unfenced `## ` line
  (`_section_lines(text, None)`, same fence rule as every section). Each line is stripped; a line starting exactly
  `**Risk**:` contributes its rest split on `,`, each value stripped. EVERY such line counts (values concatenated, so a
  second line can never hide `sensitive` behind a first `none`; `none` + `sensitive` across two lines is the "cannot be
  combined" refusal). Values compare exactly (lowercase): `Sensitive` is an unknown value, never a silently unarmed
  sensitive rule. An empty value (`**Risk**:`) or a trailing comma yields `""`, an unknown value. Duplicates are allowed
  except that `none` with anything (itself included) is refused. A fenced Risk line does not count.
  `**Risk:**` (colon inside the bold) is not the line; the missing-line error says what to write.
- **Q4 (`<k> criteria`)**: `k` = the number of distinct criterion ids checked; with no record it is `0` (and the warning
  is on stderr). A valid record never gives zero (see above).
- **Q5 (wrong cell count)**: the row gets `<who>: <n> cells; a row has 5` and its cell rules are skipped (`table_errors`
  precedent, `reuse.py:212-214`), but its first cell still counts for coverage, duplicates and the unknown-id rule, so
  one defect gives one error, not a second "no row".
- **Q6 (dashes)**: the existing set `("—", "-")` (`reuse.py:45`, `:183`). An en dash `–` is text, i.e. a case.
- **Bounded, escaped errors**: one error per Risk LINE SET, not per value: `Risk: <n> value(s) not one of none sensitive
  contract migration; the first is <repr(first[:40])>`. Row criterion ids and failure cells are echoed only with `%r`
  (C0/C1 arrive escaped, as `table_errors` does at `reuse.py:208`, `:219`); the failure cell is echoed only when it is one
  of the four short non-case values. Coverage, duplicate and unknown-id checks use a set and a dict
  (`dict.fromkeys(ids)`: ordered, O(1) lookup).
- **Who**: a row's errors start with its criterion cell when it fullmatches `AC-[0-9]+` (every id `review_tests.criteria`
  can produce has that shape, `review_tests.py:35`, `:54`), else `row <k>`. Section-level errors start `Risk:` or
  `Test design:`.
- **Missing section**: `## Test design` absent gives ONE error and no per-criterion errors (early return); the Risk errors
  still come first. Header wrong gives the header error; a right header with no separator gives the separator error
  (`elif`: one error for one defect).
- **No record, warn path**: criterion ids are `None`: the unknown-id, duplicate and coverage rules are skipped; every
  row's cell rules and the sensitive rule still run.
