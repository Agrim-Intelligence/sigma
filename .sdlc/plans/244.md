# #244 plan — stop the forked-shell locale crash in risk-detect.sh

Research: `.sdlc/research/244.md` (root cause: a per-command `LC_ALL=C grep` in a forked bash
subshell calls into CoreFoundation, which is not fork-safe, and it SIGSEGVs under load).

## Steps

1. RED (deterministic seam control): add
   `test_locale_is_pinned_once_and_never_changed_in_a_forked_shell`. It runs the gesture the docs
   use (`bash risk-detect.sh`, plus `-x`) on the untracked header-leak fixture. It asserts that the
   only traced locale assignment is the top-level `export LC_ALL=C`, and that it comes before the
   first forked (`++`) line. Non-vacuity checks: the trace reaches the untracked-loop `grep -Iq` at
   depth `++`, and the content hit lands. Seen red on the original script (it found
   `++ LC_ALL=C` and `+++ LC_ALL=C`).
2. RED (liveness): add `test_a_dead_content_scan_is_reported_not_silent`. A mutant kills the
   content-scan subshell at the untracked-loop anchor, which is exactly where the observed SIGSEGV
   hit. The mutant must reproduce the empty result, and stderr must say `content scan incomplete`.
   The real script must give empty stderr and the hit. Seen red on the original script (stderr
   was empty).
3. GREEN: in `skills/agrim-loop/scripts/risk-detect.sh`, add `export LC_ALL=C` once after
   `set -uo pipefail` and drop both per-command `LC_ALL=C` prefixes (`sort` in `cats_json`, and
   `grep -Iq` in `emit_combined_diff`). Also add a completion marker: `emit_combined_diff` ends
   with `# risk-detect:end`, the classifier awk turns it into `__end__\t`, and the main loop sets
   `CONTENT_SCAN_DONE`. If the marker is missing, the script prints one stderr line with no
   location. It stays FAIL-OPEN: exit 0 and valid JSON.
4. Control on a partial regression: keep the pin and re-add `LC_ALL=C grep`. Step 1's test goes
   red again.
5. Rewrite the header comment of `tests/test_risk_detect.py`: it records the root cause and names
   the deterministic control. The git-backed category tests are integration tests and are not the
   system of record for this race.
6. Measure: at least 60 stressed `-n 8` runs green under the same load as the baseline, plus a
   same-session A/B against the original script.
7. CHANGELOG Unreleased entry. Run the file on bash 3.2 (`/bin/bash`) and 5.3, and on py3.10 and
   py3.12. Check the private-name and self-contained guards.

## Definition of done

The seam control and the liveness control are each seen red and then green. Stress shows 0 red
in at least 60 runs where the baseline was clearly red. `loop.py verify` is green.

## Risks

- `LC_ALL=C` for the whole script changes the locale for git, awk and the bash globs. Every
  pattern is ASCII, and byte-wise matching is the deterministic choice. Git messages go to
  `/dev/null`, and path quoting follows `core.quotePath`, not the locale.
- The xtrace format differs between bash versions. Checked: 3.2 and 5.3 both trace the export as
  `+ export LC_ALL=C` followed by `+ LC_ALL=C`, and both trace a temporary assignment as its own
  line.
