## Design
- Pins (owner reviews them in the PR): two for sigma-plan-review (`The last gate before code`, `**The reviewer must not be
  the author**`) and sigma-release-check; one for each of the rest. sigma-goal pins "`sigma-plan-review` skill — never skip".
- Prose-only skills are derived from disk in tests (no `scripts/*.py|sh`), never a typed list or count (D-11).
- Real-tree wiring = a pytest that calls `smoke.check(SKILLS, CARDS)` with ZERO findings, plus one subprocess of the
  documented bare gesture `python3 evals/skills/smoke.py` from the repo root. Cost: 4 exercised fixtures, sub-second each,
  sequential (~0.1-0.2 s total measured on the bare run); O(skills + scripts), no chokepoint.
- Probe test: copy `skills/` to tmp (`shutil.copytree`, symlinks kept), add an empty `sigma-probe/`, run the runner with
  `--root <tmp>/skills`; exit 1 and `sigma-probe` named. A second, literal control is run once by hand in a scratch clone
  with the bare gesture (PR body).
- Python 3.9 compatible tests (no `match`, no `X | Y`).
