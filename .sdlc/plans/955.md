## Design

**The invariant.** A run belongs to the session that started it. Each `start` stamps a `run` block
in ITS OWN session-registry marker with the same instant it writes to STATE.md. Session-scoped
readers (budget gates, run_stop dedupe) read their own block; goal-scoped readers (verify
freshness, phase/spend credit) resolve the goal's LIVE holder(s) from the registry's `in_flight`.
No block, no holder, or a dead holder: the checkout-wide STATE.md cursor, exactly as today. STATE.md
is still written byte-for-byte as today, so the single-loop path and every legacy reader are
unchanged.

**3a. Registry storage moves down to `state.py` (D-5), verbatim, with `loop.py` aliases.**
`done_refusal` (called from `loop.py record`, `work.py pr` and `work.py merge`) and the budget
credit functions live in `state.py`, which must not import `loop.py` (state.py:1214-1215). So the
storage half of the registry moves; identity, lifecycle, admission and prune stay in `loop.py`:

| `loop.py` today (line) | becomes in `state.py` | `loop.py` keeps |
| --- | --- | --- |
| `_CODEX_THREAD_ID` (2420) | `SESSION_THREAD_ID` | `_CODEX_THREAD_ID = state.SESSION_THREAD_ID` |
| `_session_dir` (2411) | `session_dir` | alias |
| `_session_lock_path` (2529) | `session_lock_path` | alias |
| `_session_locked` body (2541) | `session_locked(sdlc_dir, entry_path, fn, require_lock=False)` | 3-line wrapper resolving `path or _session_marker_path(sdlc_dir, session_pid)` |
| `_session_read` (2587) | `session_read`, plus `"run": session_run(data.get("run"))` in the valid return and `"run": None` in the invalid one | alias |

Docstrings move with their code. `liveness_prune.py` and every test keep calling the `loop.`
names. `_session_codex_thread`, `_session_marker_path`, heartbeats, `session_start`/`session_end`,
`_prune_dead_session_entries`, admission and claim/release stay put.

**D-1, prerequisite.** `session_write(path, data)` merges every key of the existing marker that
`data` does not carry (today: `generation` only). The four partial writers (`_reserve_goal_slot`,
`_cancel_goal_slot`, `_session_claim`, `_session_release`) and `session_start` therefore keep the
`run` block. An unreadable existing file preserves nothing, as today. No writer relies on dropping
a key (checked: each passes `in_flight`/`settled_admissions`/`generation` explicitly; a legacy
marker with an absent `settled_admissions` stays absent).

**3b. The run block, and one instant for both anchors.**
`run = {"started_at": float, "tokens": int, "codex_raw_tokens": int, "token_credits": [key],
"codex_token_credits": {key: int}}`. No `phase_ends`: it only drives `phase_report`'s journal
dedupe and stays global. `state.session_run(raw)` normalises (dict; `started_at` a finite number
> 0, not bool; counters non-negative ints; credits a list of str and a dict of str to non-negative
int) or returns None. `state.fresh_session_run(now)`.
`state.reset_session_run(sdlc_dir, entry_path, now)`: under `session_locked(..., require_lock=True)`,
returns False when the marker is not a file (never creates one), else
`session_write(entry_path, {"run": fresh_session_run(now)})`.
`state.start_run(sdlc_dir, now=None)`: `now = time.time() if now is None else float(now)`; the
patch is untouched, so STATE.md fields and values are unchanged.
`loop.begin_run(sdlc_dir, session_pid, generation=None)` is the ONE start helper:
`now = time.time()`; `selected = session_start(sdlc_dir, session_pid, generation=generation)`
(signature and body unchanged); when `selected is not None`,
`state.reset_session_run(sdlc_dir, _session_marker_path(sdlc_dir, session_pid), now)`; then
`state.start_run(sdlc_dir, now=now)`; return `selected`. Marker first, STATE.md second: a re-start
moves its own goals' anchor before the checkout's. Callers: CLI `start` (6142-6149: `generation =
begin_run(...)`, then the env var and `print(generation)` exactly as now; the separate
`state.start_run` call goes), `run_loop` (5550-5551), `assign._start_drain` (assign.py:483-485,
`loop.begin_run(sdlc_dir, session_pid)`). `session_start`'s signature is deliberately untouched:
`test_run_loop_cleanup_cannot_clear_an_overlapping_same_pid_successor` monkeypatches it with a
three-argument stand-in.

**3d. Credits (`state.py`).**
`_credit_targets(sdlc_dir, goal)`: live holders of `goal` when there is at least one (with or
without a block; a blockless holder reads the checkout cursor); otherwise EVERY live session.
Spend that names no goal, or a goal no live session holds, is charged to every live session: it
over-counts rather than escapes a ceiling, and it is what the shared counter did to each of them
before. `_credit_session_runs(sdlc_dir, paths, tokens=None, codex=None, key=None, started_at=None)`
takes ONE target's stripe lock at a time (`require_lock=True`, same stance as admission), never
inside `_cursor_lock`. Per target, under its lock: not a file, unreadable JSON, or no `run` key ->
skip (never recreate; a legacy session reads the checkout cursor); a malformed block -> error
`session run block malformed in <name>; start a fresh /sigma-loop session`; `started_at is not None
and started_at < run["started_at"]` -> skip (the phase predates THIS session's run; per-session
twin of the old-run guard); tokens: no key -> add; key not in `token_credits` -> cap check
(`len >= _MAX_RUN_TOKEN_CREDITS` -> error `session run token credit limit (4096 phase attempts)
reached; start a fresh /sigma-loop session`), append, add; codex: the global rule (keep the max
cumulative per key, add the delta, cap on a new key); `session_write(path, {"run": run})` only when
changed. Every target is attempted; the first error is raised as RuntimeError afterwards.
- `record_phase_end(..., codex_raw_tokens=None, goal=None)`: validation and the `_patch_cursor`

  `_credit_session_runs(..., _credit_targets(sdlc_dir, goal), tokens=amount, codex=codex_amount,

  `phase_report`'s `old_run` journal scan is untouched.
- `add_tokens(sdlc_dir, n, goal=None)`: validation and global patch unchanged; then
  `_credit_session_runs(..., _credit_targets(sdlc_dir, goal), tokens=n)` when `n`.
- `phase_report._record_end_usage` passes `goal=goal` to both calls (2000, 2009).
- `spend` verb (6572-6615): `goal = argv[4] if len(argv) >= 5 and not argv[4].startswith("--")
  else None` (pure argv) BEFORE `state.add_tokens(argv[2], tokens, goal=goal)`, which stays first

## The five properties

- **RELIABILITY.** Red measured on 5f25b99 by the documented gestures and in process (Test notes).
  Every guard has a named mutation that turns a named test red (Controls). The storage move is
  in-process to in-process, so the existing lock race tests
  (`test_session_claim_race_loses_a_goal_without_a_lock_guard`,
  `test_session_claim_and_release_race_do_not_lose_updates`) keep exercising the same code through
  the `loop.` aliases; no performance boundary is crossed.
- **SCALABILITY** (measured 2026-10-10 on this Mac, synthetic markers, `scratchpad` scripts):
  marker 4.2 KB (140 Claude attempts, about a 20-goal handoff run) / 5.4 KB (Codex), 115 KB / 152 KB
  at the 4096 cap (today: 42-111 bytes). Read + parse of every marker (`_session_entries`, once per
  scan): 0.06 ms for 1 session, 0.46 ms for 10, 4.4 ms for 100 at 140 attempts; 0.28 / 5.3 /
  53 ms at the cap. `done_refusal` gains one such scan; `_next` scans as today plus one own-marker
  read per gate. One credit = read + merge + write + fsync + replace of each target: 0.72 ms at
  140 attempts, 3.3 ms at the cap; unattributed spend with N live sessions costs N of those (100
  sessions at the cap: about 0.33 s). Ceiling: 4096 credited attempts per session, refused loudly,
  the existing STATE.md constant; session count bounded by the existing dead-session prune.
  Not measured: a network filesystem; Linux fsync cost.
- **RESILIENCY.** Crash between the STATE.md credit and a marker credit: a retried phase end
  self-heals (per-block dedupe on the attempt key); `add_tokens` has no key, so a retried `spend`
  double-counts in the block exactly as it does in STATE.md today. Dead session: ignored by the
  liveness filter at once, its marker pruned by the existing `start`/`next` sweep. A corrupt block
  degrades readers to the checkout cursor (today's behaviour) and makes credit writers refuse.
  Pre-upgrade sessions (no block) read the checkout cursor until their next `start`.
- **SAFETY.** No new process, network call or quota. Ceilings are per session: **N concurrent
  sessions in one checkout may together spend up to N x each ceiling**, the same as N sequential
  runs; this becomes the documented semantics (README). No silent defeat: another session's start
  can neither reset nor inherit a session's counters, and spend that cannot be attributed is
  charged to every live session. Without `fcntl` a marker credit refuses (`require_lock=True`),
  as `start` and admission already do.
- **LIVENESS.** `/sigma-doctor`'s budget row keeps counting an in-flight phase as credited
  (`run_token_credits` union). A bare `start-run` that cannot pick a session says so on stderr.
- **Host-agnostic.** Pure Python on the Claude `<pid>` and Codex `<pid>-<thread>` markers; no hook.
