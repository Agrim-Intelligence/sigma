# Plan 1883: the dependency-map tests stamp from the clock when called, not at import

lane: small. Tests only; no production file changes. Root cause, from `.sdlc/research/1883.md`: the
map helpers stamp `checked_at` from `NOW = time.time()` read at import or bound as a default argument.
Late in a full run that map is more than 600 s old (`dag_store.CHANGE_CHECK_SECONDS`), so it reads as
unusable and board order wins (11 instead of 10).

## Files
All are `undeclared` in `zones.py classify`, so follow the surrounding code. The guard is `new`.
- tests/test_dag_pick_1619.py: add `FRESH = object()`. `_store` defaults `checked=FRESH, built=FRESH`
  and resolves each to `time.time() - 60` when called. 1620, 1621 and 1857 call this writer.
- tests/test_auto_unpark_dag.py: same `FRESH` for `checked` only. `built` stays as it is (see Independent).
- tests/test_dag_repair_1626.py: `_map_of` and `_setup` default `checked=FRESH`; `_map_of` resolves it
  when called. 1859 calls these.
- tests/test_batch_one_read_1621.py, tests/test_dag_order_1620.py: an autouse fixture
  `_now_per_test(monkeypatch)` runs `monkeypatch.setitem(globals(), "NOW", time.time())`. These two
  pass `NOW` to a reader (`dc.chain(now=NOW)`, `chain_ranks(..., NOW)`), so once the writer is fresh an
  import-time reader clock reads the map as "future" (more than `SKEW_SECONDS` = 300 s ahead).
- tests/test_dag_test_clock_1883.py (new): the guard.

Why per-file and not one shared helper: the diff is smaller (about 24 lines) and puts nothing in
`conftest.py`, which every test loads. Each clause below was broken alone and seen red. Per-file
autouse fixtures cannot reach a writer in another module, so the writer defaults read `time.time()`
directly instead of `NOW`.

## The guard
It writes a pytest plugin to `tmp_path`. The plugin moves `time.time` forward 7300 s at
`pytest_collection_finish`. 7300 s is past both windows: 600 s for the change check and 7200 s for
2 x the 60-minute TTL. The clock is shifted, never frozen, because a frozen clock hangs polling loops.
The guard then runs
`sys.executable -m pytest -q -p no:cacheprovider -p no:xdist -p clockshift_1883` in a child process on
these files: 1619, auto_unpark_dag, 1621, 1620, 1626, and test_dag_pick_1857 and test_dag_repair_1859,
which import the 1619 and 1626 helpers. It strips `PYTEST_*` from the child's environment. It asserts
`returncode == 0`, `" passed"` in the output and no "failed", and prints the last 40 lines as the message.
It is not a time bomb: the shift is relative to the real clock and no date is written in. Cost: one
child pytest of 113 tests, about 40 s on one worker. Measured under `-n 2`: it passes, and nothing
nests under xdist.
