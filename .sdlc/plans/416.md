## 1. Facts
- `watch_daemon.py` (`state/watch.stop`), `supervise_daemon.py` (`state/supervisor.stop`) and `slack_commands_listen.py`
  (`state/slack-commands.stop`) exit when their stop-file exists; none deletes it; nothing reports it.
- D4 (`tools/readiness/drills.py run D4 --seed 1 --workdir DIR --json OUT`) records the doctor and session-start
  reporting invariants as expected failures (`control_failed_and_recorded`).
- `log.py slots` imports nothing from agrim-loop by design; it is left out and named as a gap.

## 2. Design
- New `skills/agrim-loop/scripts/stopfiles.py`: `present()`, `line()` (one line, age included, "" when none), CLI
  `stopfiles.py line <sdlc_dir>`. Read-only, never raises, never removes a file.
- `doctor.py`: new row "daemon stop-files (state/*.stop)" via `_load_loop_script("stopfiles")`, independent of any flag.
- `hooks/session_start.sh`: one tier, before the watcher-staleness tier, shelling out to `stopfiles.py line`
  (accelerator only; logic is Python).
- `drills.py` D4 expectation flips to `reporting_invariant_passed`; its tests follow.

## 3. Failure modes / scale
Per-sdlc cost is three `lstat` calls. A missing state dir, unreadable file or load failure yields "none"/a
COULD NOT CHECK row, never an exception. Unbounded growth: none.

## Tests
- `tests/test_stopfiles.py`
- `tests/test_readiness_drills.py::test_d4_runs_real_stop_file_daemon_and_both_reporting_controls_pass`

## 3b. Added after review (round 1)
- Each stop-file uses its daemon's own predicate (watch: `is_file`; supervisor, slack: `exists`). A dangling symlink
  is never a stop; a directory named `watch.stop` is reported as "present but not a regular file", not STOPPED.
- Unreadable `state/` is "COULD NOT CHECK ... not an all-clear" in doctor and the CLI, not "none".
- Unknown age prints "age unknown". The wizard tier preempts the hook line; doctor's row always covers it.
