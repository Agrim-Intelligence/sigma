# #240 Plan — Sigma and the plugin under its previous name on one repository

`<old>` = the previous name (spelled only through `legacy.RETIRED`, never whole in a shipped file).

## Decisions (recorded; nobody available to ask)

- D1 One new stdlib module `skills/agrim-loop/scripts/coexist.py` (CLI `check`/`--help`), loaded by
  path from every surface. `assess(sdlc_dir, ...)` returns a `Report` of signals, each
  `(kind, level, detail)`, `level` in {`active`, `note`}. Injectable roots for tests:
  `claude_dir` (default `$CLAUDE_CONFIG_DIR` or `~/.claude`), `codex_dir` (`$CODEX_HOME` or
  `~/.codex`), `repo_root` (the `.sdlc`'s parent), `now`.
- D2 Signals. ACTIVE (the other plugin can act on this repo right now):
  (a) Claude Code `enabledPlugins` resolves `<old>@*` to true (local > project > user);
  (b) Codex `config.toml` has `[plugins."<old>@*"]` with `enabled = true`;
  (c) a hand-registered hook whose command names `<old>` in any of those settings files;
  (d) a LIVE watcher on this `.sdlc` (pid alive + heartbeat fresh, the watcher's own rule) that
      Sigma did not start — `state/watch.owner` does not name that pid — while any other `<old>`
      signal is present;
  (e) `state/owner.json` names a plugin other than Sigma.
  NOTE (reported, never refused): installed-but-disabled; old schema ids in state (bounded scan,
  200 files); an old-name Cursor rule or Codex `AGENTS.md` block; an unmarked live watcher with no
  other signal (a Sigma watcher started before this release reads exactly so).
- D3 Per-surface decision:
  | surface | decision |
  |---|---|
  | `sdlc_init.py` | REFUSE (exit 2, before any write) when ACTIVE |
  | `loop.py start` | REFUSE (exit 2) when ACTIVE |
  | `watch_daemon.py` | REFUSE (exit 2, tee'd to watch.log) when ACTIVE; a live foreign watcher is never doubled (the shared pid lock) and is NAMED instead of "nothing to do" |
  | `loop.py _ensure_watcher` | does not spawn when ACTIVE; one stderr line |
  | `migrate.py --apply` | REFUSE when ACTIVE (migrating while the old plugin runs makes it read empty state) |
  | `doctor.py check` | WARN row `coexistence`, proceeds |
  | `status.py` | proceed; one stderr WARN line |
  | `log.py` | proceed, no check: it reads only the local action log and imports nothing from agrim-loop by design (recorded deviation from the brief) |
  | session-start hook | accelerator: injects the same one message as context; decides nothing |
  Idempotent where both may run: the watcher lock files are shared by both plugins, so at most one
  watcher runs per `.sdlc` whichever plugin starts it.
- D4 Override: `SIGMA_ALLOW_COEXIST=1` (exactly `1`; nothing derived; not read under the old
  prefix). It lets the write surfaces proceed with a stderr warning. It never lets a second watcher
  start — the lock does not consult it.
- D5 Owner markers (Sigma writes, the old plugin never does): `state/owner.json`
  `{"schema": "sigma/owner@1", "plugin": "sigma"}` written by init and loop start (atomic);
  `state/watch.owner` = `sigma <pid>` written by the watcher inside its decision mutex, removed by
  its ownership-checked cleanup. `watch.pid`'s own format is frozen and unchanged.
- D6 One message, naming the fix: disable one plugin for this repo (the exact `claude plugin
  disable <id>` / Codex `enabled = false` line), then `migrate.py`; or set the override.
- D7 Test hermeticity: `tests/conftest.py` pins `CLAUDE_CONFIG_DIR`/`CODEX_HOME` to empty temp dirs
  for every test (the dev machine has the old plugin enabled user-wide).
