## Files
- `tools/rename_check.py` (new): the check. Reads `git ls-files -z` of the repo containing the CWD (or a given root);
  searches the RAW BYTES of every tracked path and file, case-insensitively, for the old name after removing allowlisted
  tokens; a file that fails to decode is never skipped. Prints `path:line: text` (path-only for a name or binary hit),
  exit 1 if any, 0 if none, exit 2 REFUSED (stderr, empty stdout) outside a git repo. The old name is spelled from
  fragments so neither tool nor its tests trip the check. Documented gesture: `python3 tools/rename_check.py` from any
  directory in the repo, no flags. Allowlist, deliberately narrow:
  - tokens (removed before matching, anywhere): `Agrim-Intelligence`, `Agrim Intelligence` (org name), `swapnil-<old>` (the
    owner's GitHub login), a hardware name and the two fragment spellings the private-name guards need;
  - paths: `CHANGELOG.md` (history; content only) and `docs/launch/evidence/` (recorded output at a named commit — rewriting
    it would make it claim output that commit never produced; launch evidence is re-recorded at the final tree anyway).
- `tools/rename_prefix.py` (new): the mechanical rename. Whole-directory `git mv` (so untracked `__pycache__` moves too),
  refusing (exit 2, nothing moved) if a destination already exists; repeated until no tracked path has the prefix; then
  token-aware replacement `(?:(?<![A-Za-z0-9])|(?<=\\n))<old>(?=[-_])` -> `sigma` in tracked UTF-8 files, skipping only the
  path allowlist above; prints every path moved and file changed; second run prints nothing and changes nothing;
  `--dry-run` lists without writing. Imports the allowlist from `rename_check.py`. Executable bits are preserved by
  in-place rewrite.
