## Interfaces (fixed before coding)
- `seal_path(sdlc_dir, stem)` -> `.sdlc/state/sealed/<stem>.json`; stem checked with `state.unsafe_goal_reason`.
- `seal(root, sdlc_dir, stem, *, base_ref, plan_hash, route, timeout, exemptions=None, python=None, run=None, now=None, free_bytes=None)` -> the record dict. Refusals raise `SealRefused(ValueError)` carrying `.clause` (one of `collection-error`, `pass-on-base`, `exemption-reason`, `exemption-stale`, `exemption-unknown`, `all-exempt`, `unexpected-entry`, `bad-files`, `bad-plan-hash`, `base-unresolved`, `runner-unusable`, `timeout`, `disk`, `evidence-unpersisted`) and the test or file named in the message.
- `check(root, sdlc_dir, stem)` -> `{"sealed": bool, "problems": [{"path", "kind": "missing|differs|unexpected"}]}`; read-only; an absent or unparseable record returns `sealed: False` with a `record` problem, never an empty-problems "ok".
- `route` and `plan_hash` are PARAMETERS (D-10 reading): `plan_hash` validated 64-hex, `route` stored opaque as given. `exemptions` is a `{node: reason}` mapping (the `--seal-exempt` CLI spelling is slice 4).
- `run=` defaults to `bounded_run.run_group`; tests inject a fake for the faked-runner cases.

## Flagged defaults (owner can overturn; none block coding)
- **D-1**: with `--collect-only` clean and run exit 1, ANY `FAILED` node (assertion, ImportError/ModuleNotFoundError inside the body, NameError, any exception) is red. Refused, never red: collection error (exit 2 or `ERROR <file>`), fixture/setup `ERROR <node>`, skip, xfail, xpass, INTERNALERROR (exit 3), exit 4/5, missing summary, pytest absent. Classified by outcome and collected node id, never by `witness.classify` (it would call an in-body ImportError a collection error) and never by `partition(' - ')`. Exception class stored per red as `reason`; a body ImportError proves "symbol missing", not "assertion meaningful" (stated limit).
- **D-5**: recorded exemption keyed by collected node id with the `red_green._selected` prefix rule; reason non-empty after strip; refuse a stale exemption (the test actually fails on base), an exemption naming no collected node, and a seal where every node is exempt. Stored in `exemptions` of the record.
- **D-10**: separate record `.sdlc/state/sealed/<stem>.json`, schema `sigma-sealed/1`, carries `plan_hash`, `generation` (starts 1; slice 4 enforces the D-6 cap with no schema change), `base {ref, sha}`, `files {path: {sha256, bytes}}`, `red [{test, evidence_id, kind, reason}]`, `exemptions`, `proof {provenance, python, pytest, exit}`. `route` = the breaker's reviewer route dict, opaque. Staleness vs a later plan-review is slice 3's check.
- Witness `kind`: reuse closed enum, `assertion` for AssertionError, `other` otherwise (no new kind). Evidence id = first 16 hex of sha256 of canonical row JSON (test, file_hash, observed_at, provenance).
