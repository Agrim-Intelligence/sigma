# Plan 2107: tests/conftest.py honours PYTEST_XDIST_AUTO_NUM_WORKERS as a ceiling

Lane: small. Goal: Sigma's own suite's `-n auto` answer is the smaller of the conftest's memory answer and
`PYTEST_XDIST_AUTO_NUM_WORKERS` when that is a positive integer, so the resource guard's grant reaches it.

## Design
- `tests/conftest.py`: the hook computes its memory answer as today, then `min`s it with the variable's value
  when `int(value)` parses and is >= 1. Unset, empty, whitespace, zero, negative, non-numeric: unchanged. The
  variable never raises the count. The 2000 MB figure is untouched.
- The hook is not split: the test fakes `_ram_mb`, `os.cpu_count` and the environment and calls it.
- `docs/parallelism.md` verify-workers bullet: a project conftest that implements `pytest_xdist_auto_num_workers`
  overrides the variable unless it reads it (xdist's own implementation is `trylast`); Sigma's own conftest reads it.
- `CHANGELOG.md` Unreleased entry, with what was not measured.

## Tests (tests/test_conftest_xdist_ceiling_2107.py)
- AC-1: variable 1, memory answer >= 2 -> 1.
- AC-2: unset, empty, zero, negative, non-numeric, float text -> memory answer unchanged.
- AC-3: variable above memory answer -> memory answer.
- AC-4: the docs bullet carries the override sentence.
- Hand check (not a test): `-n auto` over the new file at a cap of 1, 2 and none.
- Controls: break the `int` parse clause, the `>= 1` clause and the `min` on their own; each goes red.

## Not measured
A full `loop.py verify` of this suite under a real grant; any machine other than the developer Mac.
