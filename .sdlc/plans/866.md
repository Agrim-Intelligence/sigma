## Public API of `evals/regression/layer1.py`

```python
PREFIX = "sigma-regression-layer1-"            # scratch root name prefix
MARKER_NAME = ".sigma-regression-layer1"       # file in the scratch root
MARKER_TEXT = "sigma-regression-layer1/1"
STALE_SECONDS = 86400
SESSIONS = ("init", "loop")                    # order is the contract
GITHUB_SHAPED = ("GH_", "GITHUB_", "GIT_")     # env-name prefixes never handed to the arm

class Layer1Refusal(Exception):                # .code, .detail (typed refusals, never a traceback)

@dataclasses.dataclass(frozen=True)
class RunSpec:
    commit_rev: str                 # rev of the code under test, resolved by sigma.resolve_commit
    source_repo: str                # repo the plugin export is taken from
    goal_file: str                  # path to the fixed goal file (slice-3 fixture; tests pass a stub)
    prompts: Mapping[str, str]      # {"init": ..., "loop": ...} templates, REQUIRED, no default text
    model: str; belt: str; deadline: float; rates: Any   # required; None -> Layer1Refusal "param-required"
    permission_mode: str = "auto"
    verify_command: str = ""        # written to config verify.command
    verify_enforce: bool = False
    session_env: Mapping[str, str] = dataclasses.field(default_factory=dict)  # extras (e.g. CLAUDE_CODE_SESSION_ID); NOT set by default. NEVER a bare `{}` default: a dict default raises ValueError at class definition on a frozen dataclass (plan-review #3)
    artifact_dir: str = ""          # REQUIRED: "" or None -> Layer1Refusal `artifact-dir-required` (explicitly defined, plan-review #10); result rows are copied here BEFORE cleanup
    tmp_root: str = ""              # default tempfile.gettempdir(); ALWAYS os.path.realpath-normalised before use (macOS /var -> /private/var)

@dataclasses.dataclass(frozen=True)
class SessionSpec:                  # the ONLY thing an arm receives
    name: str                       # "init" | "loop"
    index: int                      # 0 | 1
    run_dir: str                    # <root>/<name>  (absolute)
    profile_dir: str                # <run_dir>/profile, EMPTY when arm is called
    plugin_dir: str                 # <run_dir>/export
    repo: str                       # scratch clone (shared by both sessions; absolute)
    prompt: str
    env: Mapping[str, str]          # explicit allowlist, see below
    permission_mode: str; model: str; belt: str; deadline: float; rates: Any
    not_representative: bool

@dataclasses.dataclass(frozen=True)
class Scenario:
    root: str; repo: str; remote: str; gh_state: str; goal_path: str   # run-dir layout matches record.build_record defaults:
                                                        # <root>/repo, <root>/remote.git, <root>/gh_state.json
    bin_dir: str; sessions: tuple[SessionSpec, ...]
    config_written: Mapping[str, Any]   # dotted key -> value READ BACK from the file
    assumptions: tuple[str, ...]        # every unverified #865 default, emitted in the result

# Arm contract: any callable `arm(session_spec: SessionSpec) -> result` where result is a mapping/Attempt-like
# with optional keys {cost, session_id, returncode, timed_out, detail}. Exceptions (incl. KeyboardInterrupt)
# propagate AFTER cleanup. The arm gets credentials from ITS caller; layer1 never reads or forwards any.

def build_scenario(spec: RunSpec, root: str | None = None) -> Scenario   # `root` is passed in by run_scenario, which created it INSIDE its try (plan-review #4); with root=None (direct callers) build_scenario creates its own and removes it on ANY exception (BaseException) before re-raising
def write_run_config(repo: Path, spec: RunSpec) -> dict      # READ-MODIFY-WRITE of the config init scaffolded: refuses `config-missing` if <repo>/.sdlc/config.json is absent; loads it, sets ONLY the dotted keys below (unrelated keys survive), atomic write (temp + os.replace), reads back, returns {dotted_key: value}
def build_env(paths, session_env, profile_dir) -> dict       # explicit-allowlist env (see below); refuses colliding/GitHub-shaped session_env keys
def run_scenario(arm, spec: RunSpec) -> dict                 # driver: root created inside try -> build -> init arm -> write_run_config -> loop arm -> rows -> copy -> cleanup(finally)
def cleanup(root, *, tmp_root=None) -> None                  # realpath-normalised, marker+prefix guarded removal (the one removal site); raises Layer1Refusal (ArmRefusal from common.remove_tree is converted)
def sweep_stale(tmp_root=None) -> list[str]                  # prefix + marker text + real dir + own uid + age > STALE_SECONDS
```

ORDER (plan-review #2; design: config written AFTER the init session, BEFORE the loop session, because `/sigma-init` scaffolds `.sdlc/config.json` via `skills/sigma-init/scripts/sdlc_init.py` and would otherwise overwrite or race it): the driver calls the init arm, then `write_run_config(repo, spec)`, then the loop arm. `build_scenario` therefore does NOT write the config; `Scenario.config_written` is filled in by the driver after the write. If init left no config, `write_run_config` refuses `config-missing` (no fresh file is invented).

`run_scenario` returns `{"goal_path", "sessions":[{name, profile_dir, result}], "config_written", "assumptions", "not_representative", "permission_mode", "copied_to"}`. Result row file `<artifact_dir>/layer1-rows.json` is written atomically via a tiny `_write_rows` helper (the one fs-write site besides scaffolding).

Cleanup error handling (plan-review #10): `common.remove_tree` raises `ArmRefusal`, not `Layer1Refusal`; `cleanup` catches it and raises `Layer1Refusal cleanup-failed`. Called from `finally`, cleanup must not mask the arm's original exception: `run_scenario` catches any cleanup error there, attaches it (`original.__notes__`/`add_note` or `__context__` kept intact via `raise` of the original), and re-raises the ORIGINAL; if there was no original, the cleanup error is raised.

`assumptions` (always emitted, each prefixed `unverified:`): skill invocation form of the prompts (`/sigma-init` vs `/sigmaloop:sigma-init`; plugin name `sigmaloop`); whether `CLAUDE_CODE_SESSION_ID` reaches the loop shell (not set); subagent dispatch / `subagents/*.jsonl` layout (not read here); permission-mode representativeness; sibling-of-profile rule not measured against the real launcher; fixed goal file is a stub until slice 3.

Env allowlist (AC-3, plan-review #5): `evals/bench/arms/common.py::isolated_env` (lines 104-112) forwards its WHOLE input mapping except `SIGMA_BENCH_*`, so it must never be handed `os.environ`. `build_env` first builds `base_env` from an EXPLICIT allowlist read from `os.environ`: `PATH` (= `<bin_dir>:` + inherited PATH, bin FIRST), `LANG`, every `LC_*`, `TZ`, `TERM`, `SHELL`, `USER`, `LOGNAME`; plus the three absolute `FAKE_GH_STATE`, `FAKE_GH_LOG`, `FAKE_GH_UNHANDLED`. Only then is `common.isolated_env(base_env, profile_dir)` called (it adds HOME/CLAUDE_CONFIG_DIR/CODEX_HOME/TMPDIR for that session's profile). `spec.session_env` is applied last, and `build_env` REFUSES (`Layer1Refusal env-collision`) any `session_env` key equal to `PATH`, `HOME`, `CLAUDE_CONFIG_DIR`, `CODEX_HOME`, `TMPDIR`, or starting `FAKE_GH_`, and (`github-shaped-env`) any key starting `GH_`/`GITHUB_`/`GIT_`. Test `test_env_is_allowlist_only` poisons `os.environ` (monkeypatch) with `GH_TOKEN`, `GITHUB_TOKEN`, `GIT_AUTHOR_NAME`, `SIGMA_BENCH_X`, `SOME_SECRET_KEY`; none reaches the arm env, and the arm env's key set is a subset of the allowlist + the four isolated vars + `session_env`. Control: pass `os.environ` through instead of the allowlist -> red.

Git identity (AC-2): git subprocess env is scrubbed of inherited `GIT_*`, sets `GIT_CONFIG_GLOBAL=/dev/null`, `GIT_CONFIG_NOSYSTEM=1` (as `tests/regression_fixture.py::_git_env`); git is invoked via a single `_git` helper whose env is built from the allowlist plus the two config-isolation vars (never a copy of `os.environ`); identity via `git -C repo config user.name/user.email` only; the env handed to the arm contains no identity.

## Five properties

- RELIABILITY: nothing here claims the real launcher accepts the layout; README and `assumptions` say "not measured against the real launcher". Config keys are read back from disk and checked against the actual readers in the repo (`ledger.journal_enabled`, `work._plan_review_on`). No performance or cost claims are made; the result contains the arm's cost only as the arm returned it.
- SCALABILITY: one run = two sequential sessions; per-run cost is two exports (three small trees) plus one tiny repo, independent of repo size; the only serialised chokepoint is the sequential driver (by design, ceiling = 2 sessions per run; parallel cells belong to live.py/#810). Growth is bounded: crashed-run scratch dirs are swept by age (1 day); artifact rows are one small JSON per run, pruning is the operator's artifact-dir policy (stated in README).
- RESILIENCY: arm exception, KeyboardInterrupt and copy failure all end in `finally` cleanup; SIGKILL/power loss leaves a marked dir that the next run's `sweep_stale` removes (polite: marker + prefix + uid + age; never touches an unmarked dir). Re-run is idempotent (fresh `mkdtemp` per run, no shared state). The cleanup lever never stalls anything (no lock).
- SAFETY: POSIX only, refuses loudly otherwise (`require_posix`); scratch outside CLAUDE.md/.claude/.mcp.json ancestors; removal gated by prefix+marker+text+real-dir+uid; no credential read, written or logged by layer1 (it never touches the credential var; GitHub-shaped env names refused; test asserts no `TOKEN|KEY|SECRET` names in the arm env and none in the config file); git push only to a local bare remote; non-forced; deadline/belt/model/rates are required inputs, not constants copied from a developer laptop. No background processes, no network, no spend.
- LIVENESS: no long-running component is introduced. A died run is distinguishable: result rows are written before cleanup and carry per-session status; a run that never wrote rows is visible by the leftover marked dir whose age the sweep reports (`sweep_stale` returns the removed paths and the README names the age rule). Revival trigger lives in layer1's own Python (`run_scenario` begins with the sweep), not a Claude Code hook (host-agnostic).
