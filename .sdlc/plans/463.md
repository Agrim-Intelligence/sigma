## Scale / recovery
All guards read scratch trees or the checkout; no writes outside scratch. Recovery for the pruner: it is
fail-open and idempotent; a crash mid-`rmtree` leaves a partial `wt` that the documented lever (or a later
terminal record of the same goal) removes; nothing retries it automatically, and the doc says so. Web
retention is rename-only, so a crash loses nothing and the next pass continues. Restore from backup
restores the same files; no state outside them. No process pausing.
