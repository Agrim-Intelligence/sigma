## Design
- `run`: select rows (`--regression` matches row id or regression; `--changed-files` matches a row's anchor file, a gate argv path, or anything under `evals/regression/`). `--repo DIR` (default this repo) for tests.
- `git archive HEAD` into tarfile stream -> base dir under `tempfile.mkdtemp("sigma-regression-")` holding a marker file; baseline: each distinct live gate once on the base (nonzero/timeout => print all, exit 3); per row: `shutil.copytree(base, rowdir)`, `python3 <copy>/evals/regression/mutators.py apply ...` (10/11/12 pass through), run each live gate, require nonzero and != 5 (5 and timeout => exit 6 gate-vacuous/gate-timeout), 0 => exit 1 naming row and gate. Pending gates print `PENDING row gate: reason`; exit 4 only with --strict. Exit = code of the first failure in row order.
- Gate argv `python3` -> `sys.executable`; run with `start_new_session`, timeout kills the exact child's process group by recorded pid. POSIX only; else REFUSED exit 2.
- finally: `shutil.rmtree` of the one recorded parent path. Startup sweep removes only `sigma-regression-*` dirs that are real dirs, same uid, carry the marker, older than a day.
- Header states: committed state only, short sha (D-6). No network, no model, no `gh`.

## Refinements from plan-review (SOUND-WITH-REFINEMENTS)
- Red means nonzero AND not a crash: pytest gates need exit 1 (5 gate-vacuous, 2/3/4 gate-broken, negative/launch failure gate-broken, timeout gate-timeout), all exit 6; non-pytest gates need a positive exit. Baseline stays "exit 0 or exit 3".
- Unknown `--regression` exits 2; `--changed-files` matching nothing prints "0 rows selected", exit 0. Mutator exit 2 passes as 2. Run all rows; final exit by severity 10, 11, 12, 1, 6, then 4 (strict).
- Gate env scrubbed of `GIT_*`, `PYTHONPATH`, `SIGMA_*`; `PYTHONDONTWRITEBYTECODE=1`; `git -C repo archive`; copytree `symlinks=True`; tar `filter="data"`. Design departure stated: one shared baseline per distinct gate on the base copy (design cost note), no `requires` field, no `--record` (slice 4, #1059).
- Sweep: lstat, same uid, gettempdir only, marker holds a token, marker mtime older than a day, marker mtime refreshed per row; rmtree tolerates read-only files; SIGTERM raises SystemExit so finally runs; killpg only while `poll()` is None.
- Tests: fixture gates read the mutated file (green = not mutated); tree hash covers every file incl. ignored; a green control on the unmutated real tree beside the red double-context.
- `catalogue.py check` re-run after gates.json edit; safety-check green at baseline measured 3.7 s.
