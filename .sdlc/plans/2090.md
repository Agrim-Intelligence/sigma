## Goal

A Claude Code cloud environment, `sigma-cloud`, where one session runs `/sigma-goal <N> --land` on one issue of
this repository and ends merged, parked or failed. Its setup script lives here (`tools/cloud/setup.sh`) and is
loaded with the setup-script dialog's Choose file.

## Design after plan review

The first draft copied the maintainers' untracked sharded runner into the container. Plan review found that the
approval would not cover the runner's bytes, that the runner drops every dash argument, and that the copy would
drift. Verify is instead CI nightly's own command on `-n auto`, so the resource guard grants the worker count
(`PYTEST_XDIST_AUTO_NUM_WORKERS`). Cost: no serial retry of tests that fail only under load; revisit if the
first measured run shows such failures.

`tools/cloud/setup.sh`, all steps non-fatal, each failure a `sigma-cloud: WARNING` line, `exit 0`:

1. git from the git-core PPA when older than 2.46; key F911AB18... pinned by full fingerprint, the only key in
   the keyring; PPA judged by `apt-cache policy git`; one retry after a killed install.
2. pytest, pytest-xdist, PyYAML in every `python3` on PATH (`uv pip --system`, then `pip`), Python >= 3.10.
3. Sigma Loop from the marketplace, `update --scope user`, version >= 1.0.21 checked.
4. `.sdlc/config.json` from the installed Sigma's `config.json.tmpl` plus: GitHub backlog for this repository,
   `@me`, board off, ledger off, `model_selection: off`, `verify.enforce`, `verify.timeout_minutes: 240`
   (loop.py's default kill is 60), `verify.command`, `work.enabled`, `auto_merge: protected`,
   `require_review: approval`. `project.md` from its template when absent. A leftover git-local
   `sigma.allowRepositoryShellCommands` is unset.

Dropped after review: a `~/.claude/settings.json` permissions section (not in the issue, broader than needed,
unmeasured). Left at the template's values on purpose: the budget (checked only at the pick, so a laptop's
500,000-token cap never stops a `--land` run) and `work.allow_secret_content` (a laptop's entry is one goal's
test fixture).
