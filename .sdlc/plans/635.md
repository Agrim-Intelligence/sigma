## Design
In `work.py`: `_TRUSTED_ASSOCIATIONS = ("OWNER", "MEMBER", "COLLABORATOR")`, read from each comment's `authorAssociation` in the SAME `gh pr view --json comments,author` call (read-only, no new request). In `_comment_directive`, a comment whose `_line_directive` is a marker but whose association is not in the set (including absent/unknown) is skipped, never applied, and one line is printed to stderr per such comment: `sigma: ignoring a sigma:<marker> comment on PR #N from <login> (<association>): only OWNER, MEMBER or COLLABORATOR comments are honoured`. All three markers are treated alike (an untrusted `sigma:unblock` must not clear a block; an untrusted `sigma:block` must not let a stranger park the loop). Latest-trusted-marker-wins, same_author and the #821 self-approval warning are unchanged (a trusted author approving their own PR stays honoured and loud: docs/enforcement.md and the README document that solo-account repos need it).
Fail closed: if the comments call fails or returns unparseable JSON, `_comment_directive` raises and `review_gate` returns `(False, "could not read PR #N's comments ... re-queue once gh works")` for modes changes/approval (the gate cannot know whether a trusted block exists). The separate `reviewDecision` read keeps its documented fail-open (named follow-up, not widened here).
Lever and recovery: an approver who is not OWNER/MEMBER/COLLABORATOR is added as a collaborator (or leaves a formal GitHub review, which GitHub itself restricts to write access); the ignored comment stays on the PR and the stderr note names it; no state to repair, the next gate run re-reads comments. Cost: O(comments), one call, unchanged. No new background work.
Docs: enforcement_table.py "Independent review" and "Post-PR review gate" text, regenerated docs/enforcement.md; README "What approval does NOT verify" paragraph (the gate now cares who commented, but only the repository relationship, not independence); config.json.tmpl `_require_review_2` sentence; doctor text only if it asserts "any commenter".
