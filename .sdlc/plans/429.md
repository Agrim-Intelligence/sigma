3. `_git`: `git --no-replace-objects --literal-pathspecs -c protocol.allow=never -C <root> …`; env =
   os.environ minus names whose upper case starts `GIT_`, plus `GIT_CONFIG_NOSYSTEM=1`,
   `GIT_CONFIG_GLOBAL=<os.devnull>`, `GIT_NO_REPLACE_OBJECTS=1`, `GIT_NO_LAZY_FETCH=1`,
   `GIT_TERMINAL_PROMPT=0`. `git --version` must parse `git version X.Y`, (X,Y) >= (2,32), else
   REFUSED. `rev-parse --show-toplevel`, resolved, == root resolved, else REFUSED quoting git's
   `fatal:` line (dubious ownership: also say global config, where safe.directory lives, is ignored).

   `rev-parse --verify -q --end-of-options <oid>^{commit}`, else REFUSED. Later calls name only it.
