# #241 plan — CI: fail-fast false, fix the 3-test Linux cluster

Decision (recorded, nobody available to ask): replace the monkeypatch recorder with one built on
the interpreter's audit events (PEP 578, `sys.addaudithook`), not a second patch of pathlib's
private `_NormalAccessor`. Audit events are raised by the C implementation (`_io.open` and
`os.open` raise "open"; `os.rename`/`os.replace` raise "os.rename"; `os.remove`/`os.unlink` raise
"os.remove"; "os.mkdir", "os.rmdir") whatever Python-level name reached them — same on 3.10, 3.12
and Windows. Cost, named: an audit hook cannot be removed; it is installed once per process on
first use and returns immediately while no recorder is active.

## Steps
1. New `tests/path_recorder.py` with `Recorder` (same `opened`/`replaced`/`made`/`paths()`/
   `files()` API). Both test files bind `_Recorder = path_recorder.Recorder`, removing the
   duplicated copies (the drift risk that made the fix needed in two places).
2. `.github/workflows/ci.yml`: `strategy.fail-fast: false`.
3. windows.yml: inspect only; no change needed.

## Tests / controls (definition of done)

- Restore; full suite `pytest tests -q -n 4 -p no:cacheprovider` on 3.10 and 3.12.
- `tests/test_no_private_names.py`, `tests/test_self_contained.py` green.
