## Design
- `class MutatorError(Exception)` with `.code`/`.kind`: `anchor-missing` 10, `anchor-ambiguous` 11,
  `mutation-noop` 12. `MUTATORS = {regression: {form: (file, symbol, kind, arg)}}`; kinds `body`
  (replace function body after the docstring with one return line), `value` (replace the assignment
  right-hand side), `drop-element` (delete one Tuple child by first string constant), `append-words`.
- Forms: `skip-plan-review`/`code` (`return ""`), `drop-review-recording`/`code` (`return None`),
  `disable-secret-scan`/`drop-pattern` (`huggingface-token` in `SHAPE_RULES`), `drop-redactor-only`
  (`authorization-header` in `_SECRET_PATTERN_SPECS`), `whole-table` (`SHAPE_RULES` becomes `()`),
  `commit-noop` (`_row_hits` returns None), `double-context`/`words`. No prose form (pending 805).
- `apply(regression, form, root) -> list[str]` returns changed repo-relative paths. Edits replace
  whole lines `lineno..end_lineno` of the node (`splitlines(keepends=True)`), the rest byte-for-byte.
  Write back only if the text differs, else 12. One parse per call.
- `double-context`: run `<root>/evals/phase_context_budget.py --json` (`sys.executable`, cwd root);
  first phase in sorted order whose files are all real paths; append that phase's `words` of filler
  to its `files[0]`. A failed or non-JSON run is 10; zero words is 12.
- CLI: `apply <regression> --form <form> --root <dir>` prints changed paths on stdout;
  `mutators.py: <kind>: <detail>` on stderr with the exit code; `anchors` prints one line per
  `regression form file::symbol[#entry]`; unknown regression or form exits 2. On 10, best-effort
  `candidates:` from removed `def NAME`/`NAME =` lines in `git -C <root> diff HEAD --unified=0 -- <file>`
  (not a git repo or empty diff means none). Docstring states the gestures, exit codes, and the limit
  that after a commit the diff is empty so the hint covers an uncommitted rename only.

## Test rules
Tests copy `skills`, `evals` and `examples` to `tmp_path` and mutate only the copy; a test asserts the
real files are byte-identical afterward. No home-directory path literals anywhere (roots come from
`pathlib.Path(__file__)` and `tmp_path`; anything resembling a home path is built at runtime).
Secret-shaped strings, where a test needs one, are fake and assembled at runtime from fragments.
Python 3.9 here: no `match`, no `X | Y` annotations.

## Ceilings
Per call: one `ast.parse` of a 7k-line `work.py` plus one 1 s gate run for `double-context`; linear in
file size and phase count. At 10x or 100x anchors the table walk stays linear; no lock, no state, no
network, no model, no background process. Not measured: Windows, Python 3.10 on CI (local is 3.9).

## Recovery
The engine mutates only a copy it is told (`--root`); a crash mid-write leaves one file partially
written in a throwaway tree, so re-copy and rerun. Every failure is a named nonzero exit, never a pass.
