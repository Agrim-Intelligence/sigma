## Shape of the code (sprouted directly above `status()`, kg.py:644)
```python
# graph.json can exceed 100 MB and the builder writes built_at_commit as its LAST top-level key, so only the tail is read.
_TAIL_BYTES = 65536
_HEAD_BYTES = 1048576   # code-node search window; a miss here means "unknown", never "no code"
# The pattern IS the trust boundary (FR-58): a graph file can arrive with a clone, so only full hex reaches git.
_BUILT_AT_RE = re.compile(r'"built_at_commit"\s*:\s*"([0-9a-f]{40}(?:[0-9a-f]{24})?)"')
_NODE_RE = re.compile(r"\{[^{}]*\}")   # [^{}] spans newlines: graphify json.dump(indent=2) splits a node over lines
_LINE_LOC_RE = re.compile(r"L\d+")     # used with fullmatch

def _graph_path(sdlc_dir, kg): ...       # the exact expression from status() kg.py:656-657; status() now calls it
def _is_code_node(text): ...             # "file_type" in text -> json.loads (ValueError -> False) -> dict with
                                         # file_type == "code" AND fullmatch L<digits> source_location AND str
                                         # source_file not startswith ".sdlc/knowledge/" AND not endswith ".md"
def _run_git(argv): return subprocess.run(argv, capture_output=True, text=True, timeout=30)
def freshness(sdlc_dir, repo_root=None, run=None): ...
```
`freshness` order of work (brief item 5):
1. `kg = load_config(sdlc_dir)`; `graph = _graph_path(sdlc_dir, kg)`; result starts as the 7 keys with
   `enabled = kg["enabled"]`, `built = graph.exists()`, the other five `None`. Not enabled or not built: return it.
2. One `open(graph, "rb")`: `head = f.read(_HEAD_BYTES)`; `size = f.seek(0, 2)`; `f.seek(max(0, size - _TAIL_BYTES))`;
   `tail = f.read()`. Both decoded `utf-8`, `errors="ignore"` (a 1 MiB cut can split a multibyte char). `OSError`
   (file vanished between `exists()` and `open`) returns the result as it stands. Never `json.load` on the file.
3. `holds_code = True` if any `_NODE_RE` match in `head` passes `_is_code_node`, else stays `None` (never `False`).
4. `found = _BUILT_AT_RE.findall(tail)`; none: return. Else `built_at_commit = found[-1]` (last match).
5. `root = str(repo_root) if repo_root else str(pathlib.Path(sdlc_dir).resolve().parent)`; `run = run or _run_git`.
   A local `git(*args)` calls `run(["git", "-C", root, *args])`, returning `None` on `(OSError, subprocess.SubprocessError)`.
6. `ancestor`: `git("merge-base", "--is-ancestor", "--end-of-options", commit, "HEAD")`: rc 0 True, rc 1 False, else / exception None.
   Only when `ancestor is True`:
   - `commits_behind`: `git("rev-list", "--count", "--end-of-options", f"{commit}..HEAD")`: `int` only when rc 0 AND stdout
     `.strip().isdigit()`, else `None` (Research flag 3: rc 128 with empty stdout must give `None`, not `int("")` raising).
   - `changed_files`: `git("diff", "--name-only", "--end-of-options", f"{commit}..HEAD")`: `len(stdout.splitlines())` only when rc 0.
7. Never raises from a git call; each failing call nulls only its own key.

The commit is used as-is, not resolved with `rev-parse`: it is already a full hex id (the owner rule's `rev-parse --verify
--end-of-options` applies to refs, and nothing here is a ref). A hex id that is not an object makes `merge-base` exit 128 -> `None`.

CLI (`main`, before the final `print(USAGE...)` fallthrough, kg.py:805): `if argv[1] == "freshness"`:
`print(json.dumps(freshness(sdlc, argv[3] if len(argv) > 3 else None), sort_keys=True))`; `return 0`.
`USAGE` gains `freshness <sdlc_dir> [repo_root]` after `status <sdlc_dir>`.

**Exit-0 exception, kept (Research flag 2):** `_state_guard` (kg.py:809-820 -> `state.py:330-343`) runs before `main`
and returns 2 when an argv directory holds a symlinked `state/` or `journey/` tree. That is the existing #708 safety
refusal shared by every Sigma CLI; this goal does not change it. "Exit 0 in every case" means every case that reaches
`main`. Said in the PR body. Residual, also in the PR body: `graph.exists()` raising `PermissionError` on an unreadable

## Scale, safety, liveness
- Per call: at most 1 MiB + 64 KiB read and held, whatever the graph size (100 MB graph: same cost; 10x/100x: same).
  The node regex is linear over the 1 MiB head. Git: up to 3 calls, each capped at 30 s, so worst case 90 s wall;
  `rev-list --count` grows with commits behind, `diff --name-only` with changed paths (tree diff, no working-tree scan).
- Read-only: no file written, no process left behind, no config key. The commit reaches git only after the hex
  pattern and only after `--end-of-options`; argv is a list, no shell.
- Unknown is `None`, never a guess: a later slice treats `None` as "do not use the graph".
- A node whose `source_location` is a range (`L12-20`, possible via graphify `_source_location` for string input) does not
  fullmatch and reads as unknown, the safe direction. A node with a nested dict attribute is missed the same way.
