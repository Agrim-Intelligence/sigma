## Design
- gates.json `{"gates": [{id, argv, status, pending_reason}]}`; pending needs a nonempty reason, live must have none.
- catalogue.json `{"rows": [{id, regression, form, mutation, must_be_red_by, must_be_red_in_live}]}`; `mutation` is the anchor text (file::symbol), and the checker requires it to equal the anchor field (third token) of the line `mutators.anchors()` emits for that form (imports mutators.py by path, never calls `apply`). `must_be_red_in_live` is a list of layer ids, may be empty; left free (layer ids are owned by goal 821).
- checker loads mutators.py by path, rejects (also: duplicate gate/row ids, empty argv, bad shape, malformed/missing file exit 2; `--root DIR` for tests): unknown gate id, empty must_be_red_by, no live gate in must_be_red_by, (regression, form) not in MUTATORS, a MUTATORS form with no row, duplicate ids, bad status. Prints one named line per problem, exit 1; 0 clean; 2 unreadable file.
- Row map: skip-plan-review/code -> work-plan-review-gate, layer1-control; drop-review-recording/code -> work-review-post, layer1-control; drop-pattern -> non-key-evaders, safety-check; drop-redactor-only -> scrub-tests, safety-check; whole-table -> scrub-tests, non-key-evaders; commit-noop -> work-commit-scan; double-context/words -> phase-context-budget.
- Not listed: test-first, phase-record suites (measured green under the code regressions).
