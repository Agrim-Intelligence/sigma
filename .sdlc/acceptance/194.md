## Done when
- [ ] Coverage of `skills/` and `hooks/` is measured at the current revision with a named tool and version, on a stated Python, with the exact command; subprocess-spawned scripts are included via the tool's subprocess support, and anything not measured is named. The number and command are recorded in a committed measurement file.
- [ ] Every coverage statement in README and docs equals the recorded measurement (or says CI measures none); no unmeasured figure and no private repository name appears.
- [ ] A CI coverage threshold exists only if derived from the measurement with headroom and its added CI runtime is measured and acceptable; otherwise the decision not to add one is recorded with its reason.
- [ ] A regression test fails when the README's coverage figure disagrees with the measurement file, seen red, run on the gesture the docs give.
- [ ] If coverage cannot be measured reliably, the claim is removed, the reason recorded, and one queued follow-up filed.
