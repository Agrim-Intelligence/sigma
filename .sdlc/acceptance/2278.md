## Done when
- [ ] WHEN `reuse.py check-research <sdlc_dir> <goal>` reads a research dossier whose `## Reuse` section is well formed, THE reuse validator SHALL exit 0 and print one line naming the dossier.
- [ ] IF a `## Reuse` row carries a decision outside the six allowed ones or lacks the evidence its decision requires, THE reuse validator SHALL exit 2 and name the row id and the broken rule on stderr.
- [ ] IF a `dependency-new` row lacks a `<registry>:<name>==<version>` evidence cell or a reason starting `verified:`, THE reuse validator SHALL exit 2 naming the row id.
- [ ] WHEN the `## Reuse` section records its queries, THE reuse validator SHALL accept only lines carrying one pattern and its paths, and SHALL refuse a pattern over 200 characters, more than 25 queries, an absolute path, a path containing `..` and a path starting with a dash.
- [ ] IF the dossier has no `## Reuse` section or its `## Reuse` section carries neither a `**Source:**` line nor a `**Searched at:**` line, THE reuse validator SHALL exit 0 and print a legacy warning on stderr.
- [ ] WHEN the dossier has a `## Reuse` section, THE reuse validator SHALL require a `**Searched at:**` line holding a full hexadecimal commit id of 40 or 64 characters, SHALL require that commit to exist when run with `--at-research`, and SHALL only warn when it is absent from this machine otherwise.
- [ ] WHEN a commit id is read from a dossier, THE reuse validator SHALL use it only if it is 7 to 64 hexadecimal characters and SHALL resolve it to a full commit id with `git rev-parse --verify --end-of-options` before any other git command receives it.
