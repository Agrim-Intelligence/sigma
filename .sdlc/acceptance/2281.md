## Done when
- [ ] WHEN `reuse.py rerun <sdlc_dir> <goal>` runs, THE reuse validator SHALL run every recorded query with `git grep` through an argument list and never through a shell, and print the hits for each query.
- [ ] WHEN `rerun` runs with `--new-since-research`, THE reuse validator SHALL print only the hits present on the base ref and absent at the commit the dossier's `**Searched at:**` line names, comparing hits by file and text and never by line number, and name both commits.
- [ ] IF the base ref is missing or the dossier records no query, THE reuse validator SHALL say so in one line and exit 0.
- [ ] WHEN one query runs longer than 30 seconds, THE reuse validator SHALL stop that query, report it as timed out and continue with the next.
- [ ] WHEN `rerun` or `inflight` is given a ref, THE reuse validator SHALL resolve it to a commit id before any use and SHALL refuse a ref that does not resolve.
- [ ] WHEN `rerun` runs with no ref, THE reuse validator SHALL search the tip of the base ref and SHALL NOT read HEAD.
