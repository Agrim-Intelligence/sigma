## Done when
- [ ] Every test that fails or errors on unmodified `main` in the cloud container is listed on the issue with its real cause and evidence, with no unexplained entry.
- [ ] Each is fixed at its cause (a real defect in code, a fragile or environment-dependent test made robust where it runs, a stale committed figure brought current), with no test skipped, disabled, deleted, loosened, quarantined or added to `verify.known_flakes`.
- [ ] The context-budget test passes by trimming over-budget prose or by the documented regeneration gesture, and any ceiling change is named in the pull request for the owner's approval.
- [ ] The configured full verify command exits 0 in the cloud container, shown by the run's own output, and a focused `-k` command over `tests/` no longer trips the collection memory bound.
- [ ] Any failure that cannot be fixed inside the repository is reported with evidence and the exact proposed setup-script change, and is not counted as fixed.
- [ ] Each fixed test is seen to fail when the behaviour it guards is broken (a control), and each real defect fix has a test seen red before and green after.
- [ ] `tools/cloud/README.md` records the container facts that mattered, and the affected docs are updated.
