## Done when
- [ ] A merge command reads a fragments directory and keeps, per repository, the fragment with the greatest committer time, breaking ties by commit sha, and the choice is the same for any file order.
- [ ] A fragment declaring an unknown major schema version is refused and a corrupt fragment is reported and skipped by file name; neither is silently dropped, and the report states how many repositories contributed.
- [ ] Outputs are byte-identical across reruns on the same input and are written atomically (temp file plus os.replace), so a failed run leaves previous outputs untouched.
- [ ] The command prints a skeleton report, uses the standard library only, makes no network or model call, and refuses to write outside --out.
- [ ] The public-surface, write-surface and vocabulary guards pass and the write-surface inventory is updated in the same change.
