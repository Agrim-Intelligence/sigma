## Done when
- [ ] WHEN `kg.py freshness <sdlc_dir>` runs, THE kg helper SHALL print one JSON object with the keys enabled, built, holds_code, built_at_commit, ancestor, commits_behind and changed_files and exit 0.
- [ ] WHEN the graph file exists, THE kg helper SHALL read built_at_commit from at most the last 65536 bytes of that file, SHALL look for a code node in at most the first 1048576 bytes, and SHALL NOT load the whole file.
- [ ] IF the graph is disabled or not built or carries no built_at_commit or git cannot answer, THE kg helper SHALL report each unknown field as null and still exit 0.
- [ ] WHEN the graph file names a build commit, THE kg helper SHALL use it only if it is a full hexadecimal commit id of 40 or 64 characters and SHALL pass it to git only after the `--end-of-options` marker.
