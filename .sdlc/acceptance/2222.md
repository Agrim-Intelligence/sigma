## Done when
- [ ] `acceptance.py record` accepts a goal body with `## Done when` or `## Acceptance criteria`, writes one canonical record, and still refuses a body with neither.
- [ ] A shared body helper is used by dossier slices, `sigma-scope`, `handoff.py` and `sigma-brainstorm`, and a slice's criteria are derived from its `Requirements served` lines.
- [ ] The `goal_readiness` setting (`off`, `warn`, `require`, default `warn`) is checked at promote and at pick; `warn` continues with a message and `require` parks with a stated reason.
- [ ] `/sigma-init` can scaffold the issue template without overwriting an existing file, and `/sigma-doctor` reports the mode and the count of open goals lacking criteria.
- [ ] A recorded goal's criteria cannot be edited, removed, weakened or reordered by any phase or agent: `acceptance.py`, `work.py commit` and `work.py pr` each refuse a record whose original criteria are not an exact ordered prefix.
- [ ] The extend verb appends criteria for a newly found slice only with a slice and a reason, posts them on the issue, and review blocks an added criterion that has no reason.
- [ ] Every guard clause has a test seen red when only that clause is broken, run through the documented gesture, and the affected docs are updated.
