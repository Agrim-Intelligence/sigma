## Done when
- [ ] `work.py commit` recognises a commit that failed because the host's signing helper is unavailable (git stderr has `failed to write commit object` together with a signing-helper error) and stops with one plain "commit signing is unavailable" message instead of a generic commit failure.
- [ ] The ledger publish commits in `sync.py` (scaffold, `_publish_knowledge`, `publish_receipt`) recognise the same condition, stop with the same plain message, and do not retry into the same failure.
- [ ] No path retries unsigned or adds `-c commit.gpgsign=false`; the message says Sigma will not turn signing off.
- [ ] A test simulates the outage (a `gpg.ssh.program` helper that prints an error and exits 1) and asserts the plain message for `work.py commit` and for a `sync.py` publish commit; the test is seen red before the fix.
