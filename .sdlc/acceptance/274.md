# Acceptance — #274 benchmark harness

- `evals/bench/bench.py run` refuses before an arm starts unless `--max-usd` is a positive explicit ceiling.
- A hermetic fake arm completes two fixture tasks and writes `sigma.benchmark-results/v1` rows without a hidden-root path.
- Hidden bundles are external to the repository and task trees and are copied only into a scorer scratch tree after the trusted smoke fixture exits. The smoke gesture requires an external launcher path outside untrusted trees, but location validation is not isolation and does not authorize a live arm.
- A live arm is refused until a separately reviewed, enforceable sandbox/privilege-separation protocol exists; launcher location validation alone is not treated as a boundary. Arbitrary in-process `Arm.run` callbacks are refused. The sole direct callback is the built-in trusted zero-spend smoke fixture.
