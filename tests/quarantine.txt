# The ONE quarantine list for the test suite (#2255). A quarantined test still runs and prints: it carries
# @pytest.mark.xfail(strict=False, reason="QUARANTINED <date> <#issue>: <reason>") on the test itself (no conftest
# hook: tests/test_no_skip_hooks.py forbids one), so a fixed test shows as XPASS and the row can be deleted.
# tests/test_quarantine_list.py keeps this list and the decorators in step, both ways.
# Row: <test file>::<test name> | <YYYY-MM-DD quarantined> | <#follow-up issue> | <reason>
# Rules: no row without a named reason and an open follow-up issue; never quarantine to hide a regression a
# change introduced; remove the row and the decorator in the PR that fixes the test.
